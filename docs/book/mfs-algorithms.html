前言

本书目标

本书把 MFS（Microwave Filter Synthesis，微波耦合谐振滤波器综合）Rust 库中实际实现的算法， 按概念依赖关系组织成一册技术书。它回答六个问题：

  • 一个设计规格如何逐步变成滤波器多项式和耦合矩阵？
  • 每一步为什么这样计算，公式如何推导？
  • 代码实际采用什么算法，与理论表达有什么差异？
  • 如何计算响应、群延迟并验证结果？
  • 高级功能（双工器、多工器、多频带、优化）如何复用基础算法？
  • 哪些输入可支持、哪些会被拒绝、为什么？

本书不是 README 的扩写，不是 API 列表，不是源码的逐行翻译，也不是按 Rust 文件顺序拼接的说明。 数学内容按"问题 → 模型 → 推导 → 算法步骤 → 实现映射 → 数值细节 → 可复现算例 → 边界与失败模式"的统一顺序展开。

Part I

第一篇 · 问题与数学基础

建立全书共用的语言：设计规格、归一化频率轴、二端口网络与耦合矩阵、多项式约定。

1  从滤波器规格到综合任务

1.1 本章解决什么问题

输入是一个滤波器规格（filter specification）：阶数 N、带内最小回波损耗 （return loss, RL）、期望的传输零点位置、可选的无载 Q。输出是满足规格的理想二端口网络的 耦合矩阵（coupling matrix）——一个 (N+2)×(N+2) 实对称矩阵， 可直接映射到 N 个谐振器加源/负载的物理结构。

综合任务的核心数学问题是：给定期望的幅度响应 |S11(jω)| 与 |S21(jω)|，求一个无耗、互易、与单位阻抗源/负载匹配的二端口网络。 MFS 采用 Cameron 广义 Chebyshev 方法：先在归一化低通原型域构造三个复多项式 E(s)、F(s)、P(s)（第 6–9 章），再通过部分分式残差展开把它们变成横向耦合矩阵（第 10–12 章）。

1.2 前置知识与依赖

本章不需要前文。后续章节的依赖关系见第 5 章的符号表与全书结构图。

1.3 设计规格的数学模型

一个规格由五个量描述（src/spec/types.rs，NormalizedFilterSpec 结构体， types.rs:164）：

  • 阶数 N（order: usize）：谐振器数目。约束 1 ≤ N ≤ 256 （MAX_ORDER = 256，types.rs:186；上限防止 (N+2)² 矩阵的无界内存）。
  • 回波损耗 RL ≥ 0 dB（return_loss_db: f64，必须有限且 > 0）。 带内最小 |S11| 为 10−RL/20。
  • 传输零点（transmission_zeros: Vec<TransmissionZero>）： 归一化原型坐标下的期望 S21 = 0 位置。 TransmissionZero.value = f64::INFINITY 表示无穷零点（types.rs:16-40）。 注意：规格层只拒绝 NaN；|z| ≤ 1（通带内/带边上）的零点在规格层被接受， 在近似入口被拒绝（第 6.4 节）。
  • 无载 Q（unloaded_q: Option<f64>）：响应评估时把极点移出虚轴的损耗参数； 默认无穷（无耗）。
  • 带外衰减窗（out_of_band_attenuation）：物理频率下的额外衰减要求， 由 verify::verify_against_spec 检查（第 32 章），不参与综合。

物理频率（中心频率、带宽）不在规格内，而属于频率映射（第 2 章）。 综合在归一化域完成；带通频率参数只影响零点归一化（zeros_hz → 归一化） 与最终的物理尺度变换（第 14 章 scale()）。

输入：规格 (N, RL, z₁,…,z_K)（z 为归一化传输零点，可为 ∞）。

1.7 边界与失败模式

规格层拒绝（构造时） N = 0 或 N > 256 → InvalidOrder；RL ≤ 0 或非有限 → InvalidReturnLoss（types.rs:190-196）；零点 NaN → InvalidTransmissionZero（freq.rs:47-55）。 带通构造中 center_hz ≤ 0、bandwidth_hz ≤ 0 → InvalidFrequency （freq.rs:124-134）；bandpass_edges 倒置边缘 → 派生出 bw < 0 → 同样拒绝。

更深的拒绝（通带零点、全有限不可行域、重复极点）发生在下游，见第 6.4、8.4、11.5 节。

1.8 本章小结

规格是归一化域的量；综合 = 近似（多项式）+ 综合（矩阵）+ 变换（结构）+ 评估（响应）四段流水线， 全部由类型系统串联，失败走统一的 MfsError（8 个变体，第 31 章）。下一章建立频率轴。

2  归一化频率、物理频率及映射

2.1 本章解决什么问题

综合与响应公式在归一化低通原型频率轴 ω 上成立（通带 |ω| ≤ 1）。 工程规格用物理频率 f（Hz）。本章给出两者之间的映射 ω = Ω(f) 的 全部形式、逆映射、奇异点处理，以及 src/freq.rs 的五个实现。

2.2 归一化轴与 s 域

归一化低通原型：通带 |ω| ≤ 1，阻带 |ω| > 1；ω 为实数， 对应复频率 s = jω（j = √−1）。库中 ResponseSample.normalized_omega 即此 ω；多项式以 s 为变量（第 4 章）。

2.3 低通映射

LowPassMapping（freq.rs:66-113），参数：截止频率 fc > 0。

ω = ffc (2.1)

逆：f = ω·fc。前向要求 f ≥ 0 有限；ω(fc) = 1 精确。

2.4 带通映射

BandPassMapping（freq.rs:115-188），参数：几何中心 f0 > 0、 带宽 B = fH − fL > 0。定义相对带宽 FB = B/f0。标准低通→带通变换（freq.rs:161-164）：

ω = 1FB · ( ff0 − f0f ) (2.2)

当 f0 = √(fL·fH)（几何均值）时，带边精确映到 ω = ±1。带边公式（freq.rs:626 band_edge_pair）：

spread = B² + 4f0²,   fL = −B + spread2,   fH = fL + B (2.3)

实现事实：这不是算术均值 f0 ± B/2（review P2-2 修正）。 FilterDesign::f_start_hz()/f_stop_hz()（design.rs:424-439）使用同一公式。

逆映射取正频率支（freq.rs:168-187）：

f = ωB + (ωB)² + 4f0²2 (2.4)

2.5 高通与带阻映射

高通（HighPassMapping，freq.rs:198-266）：频率倒置 ω = −fc/f（freq.rs:238）。通带 f ≥ fc 映到 ω ≤ −1。f = 0 是奇异点，钳位到 ω = −SINGULAR_CLAMP （SINGULAR_CLAMP = 1e6，freq.rs:196）而非报错。

带阻（BandStopMapping，freq.rs:268-316）： ω = −1/ΩBPF(f)，即带通变换的倒数加负号（freq.rs:272-276 文档）。 阻带边映到 +1（下边）/ −1（上边）；f = f0 奇异， 钳位 −SINGULAR_CLAMP。逆映射分两支： ω > 0（下通带）f = 2ωc²/(w + √(w² + 4ω²c²))， ω < 0（上通带）f = (w + √(w² + 4ω²c²))/(−2ω)（freq.rs:306-316）。

2.6 多频带映射

MultiBandMapping（freq.rs:472-608）持有 K 个互不相交、按中心排序的 BandPassMapping。不实现 FrequencyMapping trait（逆映射需要带索引）。 前向映射 map_hz_to_normalized（freq.rs:559-580）：把 f 分给 |Ωb(f)| 最小的带（平手取中心较低者），返回 (band_index, NormalizedSample)。 每个带在自己的归一化域里把带边映到 ±1。

2.7 频率网格

FrequencyGrid::linspace(start, stop, points)（freq.rs:645-680）： 等距网格，要求 2 ≤ points ≤ MAX_GRID_POINTS = 100_000、有限、stop > start。 map_grid_hz_to_normalized（trait 默认实现，freq.rs:35-41）逐点前向映射。

2.8 Rust 实现映射与群延迟换算

五个映射都是 Copy 结构体，构造即校验。物理网格响应经由 ResponseSolver::evaluate(matrix, grid, mapping)（response/mod.rs:142-149）： 先把整个网格映成 normalized_omegas（mod.rs:159-163），再逐点求解。

群延迟换算（第 22 章细节）：响应里的群延迟是 dτ/dω（归一化单位）。 换算成秒需要链式法则；对带通映射 dω/df = (1/FB)(1/fc + fc/f²)， 故 τ[秒] = gd·(1/FB)(1/fc + fc/f²)/(2π)。 源码文档（response/mod.rs:23-41）并记录了 2026-10-11 的 2π 陷阱： 数值 −dφ/df 是"每赫兹"，比"每秒"大 2π 倍；直接比较会读出 (2π−1)·gd 的假偏差，且该偏差随 |S₂₁| 增大、细化网格不缩小——这是单位错配而非算法错误。

2.9 边界与失败模式

拒绝 物理频率非有限或负数（带通要求 > 0）→ InvalidFrequency； 带通逆映射产生 ≤ 0 或非有限的 f → InvalidFrequency（freq.rs:180-183）； 高通逆映射要求 ω < 0 且有限（freq.rs:246-251）； 网格点数越界 → InvalidGridSize（freq.rs:648 区域）。

2.10 本章小结

所有物理频率都先变成归一化 ω 再进入综合/响应公式。带通映射用几何中心 + 相对带宽； 带边由 (2.3) 定义。奇异点钳位（而非报错）是有意选择，与跨语言基准标准一致。 下一章定义网络与矩阵。

3  S 参数、导纳与耦合矩阵

3.1 本章解决什么问题

综合的中间产物与最终产物都是网络。本章固定全书的网络模型：二端口、短路导纳表示、 耦合矩阵的结构与不变量，以及"相似变换保持响应"这一拓扑变换篇的基础事实。

3.2 二端口与 S 参数

设二端口与单位阻抗（归一化 RS = RL = 1）源/负载连接。 归一化散射参数满足无耗性（unitarity）：

|S₁₁(jω)|² + |S₂₁(jω)|² = 1 (3.1)

回波损耗规格 RL 即带内 |S₁₁| ≤ 10−RL/20。 实现事实：测试把 unitarity 作为硬门限（tests/multi_band.rs:95： max‖|S₁₁|²+|S₂₁|²−1‖ < 1e-10）；S₁₁ 零点的 dB 值有 −300 dB 地板 （magnitude_to_db，response/mod.rs:100-106，见第 22 章）。

3.3 短路导纳与耦合矩阵

耦合谐振器网络用短路导纳矩阵表示。在归一化频率 ω 下， N 个谐振器加源(节点 0)/负载(节点 N+1)的 (N+2) 节点导纳矩阵：

A(ω) = M + ω·Ir − jRS·e0e0⊤ − jRL·enen⊤ (3.2)

其中 M 是耦合矩阵（实对称，(N+2)×(N+2)）， Ir 只在谐振器对角（索引 1…N）为 1、端口对角为 0， e0、en 是源/负载单位向量。 有耗（Q 有限）时谐振器对角再减 j/Qu（response/backend.rs:130-138）， 把极点移出虚轴。

给定 A(ω)，散射参数（第 19 章推导）：

S₁₁ = 1 + 2jRS[A⁻¹]₀₀,    S₂₁ = −2j√(RSRL)[A⁻¹]n,0 (3.3)

3.4 CouplingMatrix 数据结构与不变量

CouplingMatrix（matrix/core.rs:31-36）：

struct CouplingMatrix {
    order: usize,            // 谐振器数 N
    topology: MatrixTopology, // Transversal / Folded / Arrow / Wheel(弃用)
    data: Vec<f64>,          // 行主序 (N+2)²，data[row*side + col]
}

结构约定（横向拓扑，第 12 章产物）：

  • 谐振器块 M[1..=N][1..=N] 为对角阵，对角 M[k,k] = −ωk （实 ω 域的失谐量 Bk，transversal.rs:95 区域；见第 5 章极点约定）；
  • M[0,k] = 源耦合 MSk（恒正）；M[k,N+1] = 负载耦合 MkL（带符号）；
  • 无谐振器间耦合；可选的直接源-负载耦合 M[0,N+1] = MSL；
  • 端口对角 M[0,0] = M[N+1,N+1] = 0（纯串联终端）。

对称性不变量：构造器 new_with_topology（core.rs:69-91）默认调用 assert_symmetric（core.rs:93-119），容差为尺度感知的 tol = 1e-12·max(1, |a|, |b|)（core.rs:109）——接受 Givens 旋转后的 ~1e-15 级不对称（测试 core.rs:607 接受 1e-13），拒绝 1e-6 级的明显单边项 （测试 core.rs:619）。存在显式绕过 new_with_topology_asymmetric （core.rs:121-145），仅用于折叠掩模 fixture；经此路径喂入非对称矩阵时， LU 路径的群延迟会静默算错（幅度仍对）——见第 19.5 节的已知限制。

访问器：source_coupling() = |M[0,1]|、load_coupling() = |M[N,N+1]|、chain_couplings()（core.rs:234-254）。

3.5 相似变换与响应不变量

拓扑变换的全部机制是正交相似变换：取正交矩阵 R，令

M′ = R·M·R⊤ (3.4)

由于 R 正交，M′ 与 M 同谱；又因 A(ω) = M + … 中只有 M 的耦合结构改变， 而 (3.3) 只依赖 A(ω)⁻¹ 的两个元素，理想 S₁₁/S₂₁ 完全不变。 这就是"改拓扑不改响应"的数学基础（第三篇全部成立的前提）。 Givens 旋转是只非平凡于 2×2 块的特例正交矩阵；库用 O(N) 原地实现（第 14 章）。

实现事实：变换后库可以（默认不强制）做响应不变性检查—— transform_matrix_with_response_check（transform/mod.rs:64-115）在网格上比较 变换前后的 S 参数；基准测试把容差钉死在 1e-10（tests/benchmark_standard.rs 的 response_invariance 门）。

3.6 本章小结

网络 = 耦合矩阵 M + 频率相关项 A(ω)；S 参数是 A⁻¹ 的两个元素。 所有拓扑变换都是正交相似变换，因此保持响应——这是全书反复使用的不变量。 下一章固定多项式记号与复数约定。

4  多项式、复变量、共轭及奇偶约定

4.1 本章解决什么问题

综合的数学对象是复系数多项式。本章统一：s 域与 w 域的关系、系数存储顺序、 monic（首一）约定、共轭/paraconjugate 定义、奇偶阶符号因子。这些约定不一致是 综合库最常见的数值 bug 来源（本书多处标注了历史修正）。

4.2 s 域与 w 域

公开多项式以 s = jw 为变量（w 为实辅助变量，文献里的 ω 轴）： 根 sroot = j·wroot，即 (−im, re) （generalized_ops.rs:76-78 rotate_w_root_to_s）。 系数转换（generalized_ops.rs:45-62）：

  • w→s 系数（w_to_s_coefficients）：Q(s) = Σ dk(−j)k sk ——第 k 个系数乘以 (−j)k（按 (4−k%4)%4 旋转实/虚部）；
  • s→w 系数（s_to_w_coefficients）：第 k 个系数乘以 jk；
  • 降幂 w → 升幂 s（descending_w_to_ascending_s，generalized_ops.rs:33-42）： 先翻转系数顺序再逐项旋转——Cameron 递推在 w 域降幂进行，产物 F 由此进入 s 域升幂。

上/下半平面：reflect_to_upper_half_plane（generalized_ops.rs:80-84） 把 im < 0 的根共轭到上半平面。实现事实：E 多项式在 w 域求根后反射到 上半平面再重建（第 9 章）——上半平面是 w 域的"稳定"侧（对应 s 左半平面网络极点）。

4.3 ComplexPolynomial

ComplexPolynomial（approx/complex_poly.rs:77-81）： 升幂系数向量（常数项在前），num_complex::Complex64 系数。核心操作：

  • evaluate：Horner 降幂折叠（:95）；degree = len−1（:101）；
  • add/sub/multiply/scale/derivative（:135-183）： multiply 是系数卷积（升幂）；
  • shift(x)（:110）：P(s+x) 精确移位，无求根—— Macchiarella 迭代与 Laurent 平移都用它；
  • alternating_conjugate()（:186）：Q(−s)∗， 逐项取共轭并按幂次交替变号；
  • from_real_roots / from_complex_roots（:199-217）：由根重建首一多项式；
  • roots_with(&solver)（:226）：显式选择求根器（第 29 章）。

4.4 paraconjugate 与全局奇偶因子

对实系数多项式，paraconjugate（para-Hermitian 伴侣）定义为 X̃(s) = X(−s)∗。在 s = jw 约定下，库用 alternating_conjugate 实现。关键实现事实（第 10 章详述）： Cameron 的导纳公式需要的是 (−1)N·alternating_conjugate—— 全局 (−1)N 因子（admittance.rs:58-65）区分了 "朴素 alternating_conjugate"与"Cameron 公式"：奇数阶缺它会丢阶、极点离开虚轴、得到全反射矩阵 （review 修正，有回归测试钉死）。

4.5 monic 约定

综合链中三处强制 monic，每处都有具体理由：

  1. F(s) monic（generalized_chebyshev_helpers.rs:474，Cameron 递推后）—— 使 F/εr 与 P/ε 的相对权重正确；
  2. E(w) 构造前 F(w)、P(w) 各自 monic（:417-425）—— s→w 旋转使首项变 jN 而非 1；不归一时 E 的 F/P 权重错， 这正是奇数阶虚假通带零点的根因（历史 bug，:420-424 注释）；
  3. E(s) 重建后再 monic（:443-447）——w→s 首项带 (−j)N。

normalize_to_monic（:497-505）拒绝 leading.norm_sqr() ≤ 1e-24 （零首项，NumericalFailure）。

4.6 极点域约定（P2-12）

两个"极点"概念必须区分（docs/algorithms.md §1，response/pole_expansion.rs:81-84）：

  • s 域极点：分母多项式的根 p = σ + jω₀，理想无耗网络在虚轴 σ = 0；
  • 实 ω 域极点：−Bk，其中 Bk = M[k,k] 是横向矩阵对角。 快路径（第 20 章）直接存 pole = −M[k,k]，用实 ω 组 denom = ω − pole。

横向组装时（transversal.rs:95 区域）M[k,k] = −pole.im（s 域极点 p = jω₀ ⇒ 对角 −ω₀），两边一致。

4.7 本章小结

全书记号：s = jw；升幂系数；三处 monic；paraconjugate 带 (−1)N 因子； 横向对角存实 ω 域失谐。下一章汇总符号表，然后进入第二篇的数学。

6  全极点与有限传输零点的设计模型

6.1 本章解决什么问题

给定规格 (N, RL, z₁…z_K)，广义 Chebyshev 近似要构造三个多项式 E、F、P， 使幅度响应满足：带内 |S₁₁| 等纹波（由 RL 定幅度）、 阻带 |S₂₁| 在指定位置 zk 取零。 本章先建立"特征函数"框架，说明为什么用 F/P 两个多项式，以及 为什么通带零点（|z| < 1）不可实现——这是库的一个硬边界。

6.2 特征函数与 Feldtkeller 恒等式

定义特征（characteristic）函数

K(s) = F(s)P(s) (6.1)

其中 F 承载反射零点（决定 S₁₁ 的零点位置），P 承载传输零点（决定 S₂₁ 的零点位置）。 无耗二端口与单位阻抗终端下，散射参数满足 Feldtkeller（Bode–Fano）恒等式：

|E(jω)|² = |F(jω)|² + |P(jω)|²ε² (6.2)

（E 的定义与 (6.2) 的推导见第 8–9 章。）(6.2) 要求 K(s) 在虚轴上取实值， 即 F(s)/P(s) 的虚轴值无虚部。这施加了强约束：F 的根必须关于虚轴成"反射对"分布。

6.3 传输零点的两种取值

传输零点 zk 是归一化实坐标（TransmissionZero.value）。库区分两种：

  • 有限零点 |z| ≥ 1（阻带或带边）：P(s) 的根在 s = ±jz（虚轴成对）；
  • 无穷零点（value = ∞）：对应 P 不含该因子；全极点设计（all-pole）即 "K 个无穷零点"，此时 P = ±1（常数）或仅含 j 因子（奇偶性，第 7.4 节）。

有限零点不足 N 个时用 ∞ 补齐到 N 个（pad_transmission_zeros， generalized_chebyshev_helpers.rs:104-134）：reciprocal_or_zero(∞) = 0、 safe_sqrt_term(∞) = 1（generalized_ops.rs:86-101）。 实现事实：finite_zero_count 记录有限零点个数，决定 εr 的取值（第 8 章） 与是否存在 A 多项式（第 9.5 节）。

6.4 为什么通带零点不可实现（硬边界）

入口拒绝（generalized_chebyshev.rs:28-39， generalized_chebyshev_polynomials 入口）：先 validated_transmission_zeros， 再逐个拒绝 |z| < 1（通带内）与 |z| = 1（带边），返回带域信息的 MfsError::InvalidTransmissionZero。

数学原因（E1 调查，2026-10-05，docs/continuation-plan.md §E1）： Cameron 递推需要 √(1 − 1/z²)（第 7.3 节）。 |z| < 1 时该项变纯虚 ⇒ 递推出的 F(s) 非 Hermitian ⇒ K(s) 在虚轴不取实值 ⇒ Feldtkeller 恒等式 (6.2) 以 O(1) 量级被破坏。 |z| = 1 时该项为 0 ⇒ F(j) = 0 ⇒ ε 无定义（第 8 章分母为零）。 结论：单函数实根广义 Chebyshev 原型无法实现带内零点； 带内零点需要"多函数特征"（multifunction characteristic），是未实现的研究方向（附录 F）。

注意 规格层（spec）接受 |z| < 1（只拒 NaN），拒绝发生在 近似入口。这是有意的分层：规格描述"想要的"，近似入口判定"能不能做"。

6.5 适用条件小结

  • 可支持：1 ≤ N ≤ 256；RL > 0；有限零点 |z| ≥ 1（库入口实际 |z| > 1，|z| = 1 也拒）；任意有限/无穷组合；对称或非对称零点；
  • 不可支持：通带零点 |z| < 1（typed 拒绝）；重复极点（第 12.5 节，横向链不可表示）； 全有限 + ε ≤ 1（第 8.4 节，typed 拒绝）。

6.6 本章小结

综合 = 求满足 (6.1)(6.2) 的三个多项式。传输零点分有限/无穷；通带零点因 Feldtkeller 破坏被入口拒绝。下一章给 F、P 的具体构造（Cameron 递推）。

7  Cameron 递推及 F/P 多项式

7.1 本章解决什么问题

由传输零点集合 {zk} 构造 F(s)（反射零点多项式）与 P(s)（传输零点多项式）。 F 通过 Cameron 递推逐零点累积；P 直接由零点相乘。全部在 w 域 做，最后旋回 s 域。

7.2 前置知识

需要第 4 章的 w/s 域转换（[§4.2](#sec42)）与第 6 章的零点补齐（[§6.3](#sec63)）。

7.3 Cameron 递推（w 域）

入口 cameron_recursive（generalized_chebyshev_helpers.rs:142-211）， 输入是补齐后的 N 个零点 padded_zeros（有限 + ∞）。产生两个 w 域降幂多项式 U(w)、V(w)，其中 U 就是 F 的前身。

初值（第一个零点 z₁，:163-166）：

U₀(w) = 1 − wz₁,    V₀(w) = 1 − 1z₁² (7.1)

递推（对后续每个零点 zn，含 ∞；:172-201）。记 reciprocal = 1/zn（∞→0）、temp = √(1 − 1/zn²)（∞→1）：

Uₙ = (1 − wzₙ)·Uₙ₋₁ + temp·(1 − w²)·Vₙ₋₁ (7.2a)
Vₙ = (1 − wzₙ)·Vₙ₋₁ + temp·Uₙ₋₁ (7.2b)

代码是就地展开的卷积（:179-199）：U 更新 = U·(1−w/z)（长度 +1）加 temp·V·(1−w²)（同下标加、下标+2 减）；V 更新 = V·(1−w/z) 加 temp·U——注意 V 的第二项 不带 w 因子（是 temp·U 本身）。这个"U 带 (1−w²)、V 不带"的不对称正是 Cameron 递推的关键结构。

验证：拒绝空输入（:143）、首/后续零点的零/非有限/非∞ 值（:147-150、 :172-176）。safe_sqrt_term（generalized_ops.rs:90）对 1 − 1/z² < 0（即 |z| < 1）返回 InvalidTransmissionZero—— 这是第 6.4 节拒绝的数值落点。

7.4 F(s) 与 P(s) 的构造

F(s)：把 U(w)（降幂）经 descending_w_to_ascending_s（generalized_ops.rs:33） 转成 s 域升幂，再 monic 归一（generalized_chebyshev_helpers.rs:474）。 F 的根即反射零点，落在 ±j·z 处（虚轴成对）。

P(s)（find_p_polynomial，generalized_chebyshev_helpers.rs:214-243）： 从 [1] 开始，对每个有限零点乘以 (s − j·zk)（根在虚轴）。 奇偶因子：若 (order − finite_count) % 2 == 0，整体系数乘 j （:236-241）——把 P 旋到全极点/混合零点的约定上。P 承载传输零点。

实现细节 P 的根在 ±jz（虚轴对称），所以 P(s) 实际是 s² 的实多项式乘一个可能的 j 因子。 find_p_polynomial 直接乘 (s − jz) 而非 (s² + z²)， 依赖后续 E 构造里的 monic 旋转把虚部吸收——这是库内部约定，不要"简化"成 s²+z²。

7.5 可复现锚点

文献锚定（tests/literature_fixtures.rs + src/fixtures/mod.rs 的 cameron_single_zero_exact_case）：单零点一阶递推有精确值锚点， 回归测试钉死 F(s)、P(s) 系数与 ε 计算。Cameron 2011 Fig. 21（4 阶、RL 22 dB、 两传输零点 1.3217/1.8082）的完整系数见第 13 章算例。 cameron_recursive 的单元测试 （generalized_chebyshev_helpers.rs:531 cameron_recursive_builds_expected_first_order_polynomial） 验证单零点一阶输出。

7.6 边界与失败模式

拒绝 空零点列表、非有限/零/非∞ 零点 → 入口 error；|z| < 1 经 safe_sqrt_term → InvalidTransmissionZero。递推本身是确定性卷积，无数值收敛问题。

7.7 本章小结

F 来自 Cameron 递推（w 域 U/V 卷积，U 带 (1−w²) 项）；P 由有限零点相乘 + 奇偶 j 因子。 下一章定 ε、εr（纹波幅度）。

8  ε、ε_r 与返回损耗的关系

8.1 本章解决什么问题

纹波参数 ε（和变体 εr）把"返回损耗规格 RL"翻译成多项式 E/F/P 的相对幅度权重。 本章给公式、区分混合/全有限两种取值，并说明全有限零点 ε ≤ 1 的不可行域 （一个曾经误导用户的边界）。

8.2 ε 的定义

入口 find_eps（generalized_chebyshev_helpers.rs:247-302）。

带内纹波峰值：RL 对应 |S₁₁|²_max = 10−RL/10。 定义线性纹波量（:263）：

rllinear = 10|RL|/10 − 1 (8.1)

ε 由 s = j（带边 ω = 1）处 F、P 的幅度定（:263-271）：

ε = |P(j)||F(j)|·√rllinear (8.2)

（F、P 均已 monic；在 s = j 处取模。）物理含义：ε 是带内纹波的"幅度比例因子"， 由规格 RL 与零点布局共同确定。

验证：order == 0 → InvalidOrder（:255）； RL 非有限/≤ 0 → InvalidReturnLoss（:256-258）； |F(j)| ≤ 1e-18 → NumericalFailure（分母过小，:266-269）。

8.3 ε_r：混合 vs 全有限

εr 是 E 构造里 F 项的权重（第 9 章）。取值依赖有限零点个数 （:272-295）：

零点类型条件ε_r出处
混合零点finite_count < order（至少一个 ∞） εr ≡ 1:273-274
全有限零点finite_count == order εr = ε/√(ε²−1):275-295
εr = εε² − 1  （仅当 ε > 1 有有限实值） (8.3)

8.4 全有限不可行域（review P1-1 修复）

(8.3) 要求 ε > 1 才有有限实值。近带边零点（|z| ≈ 1）或高 RL 会使 ε ≤ 1， 此时全有限公式不可行。实现事实：find_eps 在 ε ≤ 1 时返回带域信息的 MfsError::PreconditionViolation，点名可行的替代——改用混合零点 （至少保留一个 ∞，则 εr ≡ 1 恒可行），而不是让 NaN 流到 E 阶段才被通用有限性检查拦下 （2026-10-12 修复，review P1-1）。回归测试 （tests/synthesis_regression.rs:424 all_finite_infeasible_high_rl_returns_typed_error： 4 阶、RL 34 dB、4 个有限零点 → error 含 "infeasible"； :445 all_finite_feasible_low_rl_succeeds：同零点、RL 20 → εr 有限为正）钉死两侧。

诊断信息 错误消息包含实际 ε 值与替代建议（改用混合零点）。不要"修复"成返回 NaN——那是旧行为，已被类型化拒绝取代。

8.5 ε 与 RL 的直觉关系

RL 越大 → rllinear 越大 → ε 越大（纹波越"陡"）。 零点越靠近带边（|z|↓→1）→ F(j) 越小 → ε 越大，越容易跌破 1（全有限时）。 这就是"高 RL + 近带边零点 → 全有限不可行"的物理直觉。

8.6 本章小结

ε 由 (8.1)(8.2) 从 RL 算出；εr 混合=1、全有限=ε/√(ε²−1)（要求 ε>1）。 全有限 ε≤1 被类型化拒绝并给出替代。下一章用 E = F/εr + jP/ε 构造特征多项式。

9  E 多项式构造、求根与归一化

9.1 本章解决什么问题

由 F、P、ε、εr 构造 E(s)——网络的特征多项式，其根即网络极点（s 左半平面）。 这是综合链里最容易出错的环节：奇数阶的 monic 旋转与 j 因子历史 bug 都在这里。 本章给完整构造流程、求根、上半平面反射，以及辅助 A 多项式。

9.2 E 的 Cameron 公式

由 Feldtkeller (6.2)，E 由 F、P 组合。Cameron 公式（w 域，build_e_polynomial_stage， generalized_chebyshev_helpers.rs:407-465）：

E(w) = F(w)εr + j·P(w)ε (9.1)

那个 j 至关重要——缺了它，奇数阶的 P 贡献落到实部，E 的根结构全错 （:429-430 注释）。

9.3 构造步骤（关键：三处 monic）

build_e_polynomial_stage 的完整流程（:407-465）：

  1. s→w：F(s)、P(s) 各自经 s_to_w_coefficients（:417-418）旋到 w 域。
  2. 各自 monic（:424-425）：s=jw 旋转使首项变 jN 而非 1；不归一会破坏 F/εr 与 P/ε 的相对权重。这正是奇数阶曾产生虚假通带零点的根因 （:420-424 注释）。normalize_to_monic（:497）拒绝零首项 （norm_sqr ≤ 1e-24 → NumericalFailure）。
  3. Cameron 公式：按 (9.1) 组合出 E(w)（:431-433）。
  4. 求根：AdaptiveRootSolver（第 29 章：faer → Durand-Kerner → Aberth）解 E(w) 的根（:435）。
  5. 反射到上半平面：reflect_to_upper_half_plane（generalized_ops.rs:80） 把 im < 0 的根共轭到上半平面（稳定侧）（:437-440）。
  6. 重建 + w→s：由反射后根重建 E(w)，w_to_s_coefficients 旋回 s 域， 再 monic（:442-444，w→s 首项带 (−j)N）。
  7. 根也旋到 s 域：rotate_w_root_to_s（:445-448），存入 EPolynomialStage.e_s_roots（= 网络极点，s 左半平面）。

产物 EPolynomialStage（:84-101）保留 f_w、p_w、e_w、raw_roots、 reflected_roots、e_w_from_roots、e_s、e_s_roots——测试用这些中间量钉死每一级不漂移 （tests/literature_fixtures.rs 的 "structured E-stage artifacts" 门）。

9.4 为什么 E 的根是网络极点

由 (6.2)，E(jω) 的零点（在虚轴外延到 s 平面）就是无耗网络的极点位置。 E(s) 首一、根在 s 左半平面（反射保证）。横向综合（第 12 章）的对角 M[k,k] = −pole.im 正来自这些 s 域极点的虚部（[§4.6](#sec46)）。

9.5 辅助 A 多项式（全有限零点）

build_a_polynomial_stage（generalized_chebyshev_helpers.rs:328-386） 仅在 finite_count > 0 时存在（否则 a_s = None，:343-345）。 流程：

  1. 奇偶因子 j（若 (order−finite_count)%2==0，否则 1）（:347-351）；
  2. P(s)→P(w)（:353）；
  3. 对每个有限零点 zi 求 Ψi = 奇偶·(zi·√(1−1/zi²))·∏j≠i(w−zj)， 累加 Ψ_sum（:355-365）；
  4. A(w) = (order − finite_count)·P(w) + Ψ_sum（:367-369）；
  5. 求根 A(w)，旋到 s 域（:370-376）。

A 用于全有限零点的直接源-负载耦合闭式（第 12.4 节的 MSL 兜底）。 全极点时 A = None。

9.6 GeneralizedChebyshevData 汇总

端到端入口 synthesize_generalized_chebyshev_data（:467-496）串联： pad_transmission_zeros → cameron_recursive → normalize_to_monic(F) → find_p_polynomial → find_eps → build_a_polynomial_stage → build_e_polynomial_stage，产出 GeneralizedChebyshevData（:44-66）： padded_zeros、finite_zero_count、f_s、p_s、 a_s(Option)、a_stage(Option)、e_s(Option)、e_stage(Option)、 eps、eps_r。这个结构被 PolynomialSet.with_generalized 包成公开对象（第 10 章）。

9.7 数值实现细节

  • 复杂度：递推 O(N·K)（K=有限零点，卷积）；E 求根 O(N³)（伴随矩阵特征值，第 29 章）； 反射 O(N)。
  • 容差：monic 零首项门 1e-24；求根器链见第 29 章（faer 后向残差门 1e-3）。
  • 回退：E 求根走 AdaptiveRootSolver 三级链；反射保证极点稳定（上半平面）。

9.8 边界与失败模式

拒绝 E 首项零（monic 失败）→ NumericalFailure；求根失败（三级链全败）→ NumericalFailure； F(j) 过小的 ε 计算在上一章已拦。反射后若仍有非有限根，roots_contain_non_finite （complex_poly.rs:872）会在求根门失败。

9.9 本章小结

E = F/εr + jP/ε（w 域），三处 monic + 上半平面反射。A 多项式仅全有限零点存在。 E 的根 = 网络极点。下一章把 E/F/P 变成导纳多项式 Y₁₁/Y₁₂/Y₂₂。

10  导纳多项式构造

10.1 本章解决什么问题

把 E、F/εr、P/ε 拼成二端口短路导纳矩阵 [Y] = (Y₁₁, Y₁₂, Y₂₂) 的三个分子， 共享一个分母（第 3 章 (3.2) 的 A(ω) 的耦合部分）。这是"多项式 → 网络"的桥梁。 本章给对称 Cameron 四元构造、首项抵消守卫、奇偶因子与降级兜底。

10.2 入口与前置

10.3 paraconjugate 与全局奇偶因子

记 paraconjugate（第 4 章）：X̃ = X(−s)∗，库用 alternating_conjugate 实现。关键（admittance.rs:58-65）： Cameron 公式需要 全局 (−1)N 因子。记

parity = (−1)N ∈ {+1 (偶阶), −1 (奇阶)} (10.1)

实现事实：conjugated_e = alternating_conjugate(e_normalized)·parity、 conjugated_f = alternating_conjugate(f_over_eps_r)·parity（:74-76）。 奇数阶缺这个因子会丢阶、极点离开虚轴、得到全反射矩阵（历史 bug，有回归测试钉死）。

10.4 对称 Cameron 四元构造

先缩放（:34-37）：f_over_eps_r = F/εr、 p_transfer = P·(−2/ε)。四元（:78-90）：

denominator = E + F/εr + (F/εr)̃ + Ẽ (10.2)
Y₁₁ = E − F/εr + (F/εr)̃ − Ẽ (10.3)
Y₂₂ = E + F/εr − (F/εr)̃ − Ẽ (10.4)
Y₁₂ = P·(−2/ε) (10.5)

其中 Ẽ、(F/εr)̃ 都带 (10.1) 的奇偶因子。Y₁₂ 承载传输零点 （MSL 从这里或第 12.4 节闭式兜底来）。归一化 RS = RL = 1。

10.5 首项抵消守卫（防御性）

admittance.rs:46-58：仅当 E(s) 首项系数为负且与 F/εr 首项相消 （|e_lead + f_lead|² < 1e-20 且 e_lead.re < −1e-15）时取反 E。 实现事实：库内部路径上 E 在 build_e_polynomial_stage 末尾已 monic （首项恒 +1+0j，实测 order 4/6/8），F/εr 首项 1/εr ∈ (0,1]， 两首项相加恒在 (1,2]，守卫不触发（no-op）。它只保护经公共 pub 字段直接构造 非 monic e_s 的误用路径（用户手搓 GeneralizedChebyshevData 时 E 首项可为负， 守卫此时生效）。

勿据旧注释"修复" 旧版注释曾声称 "N mod 4 == 2 时 E_lead = −1 导致相消"——那是 re-monic（:447） 引入之前的状态，现已失效。该守卫是 no-op 防御，不是活跃算法路径。

10.6 降级兜底（degree-loss）

admittance.rs:92-105：若四元构造因数值噪声丢阶 （denominator.degree() < order），退回简化的两元 Cameron 式 denominator = E + F/εr 等（alt_* 分支）。 这是有意的紧急路径，不是主算法；正常配置不触发。

11.1 本章解决什么问题

11.4 求根、重根聚类、Laurent 主部

重根聚类（:219-258）：求解器把真 m 重根拆成 ~1e-5 内的 m 个根。 单链聚类（单链 = 根离任一已分配成员 ≤ CLUSTER_TOLERANCE = 1e-5，:220， 判定 :243-247）。极点 = 簇内均值（:253-256），重数 = 簇大小 （:257-263，不从 shift 后系数向量重推——病态）。 依据：真 m 重根被拆到 ~1e-7（二重）~1e-5（三重）内，而不同滤波器极点间距 ≥ ~1.6e-3。

Laurent 主部（principal_part，:318-365）：把分子分母平移到极点 p （P(x)=num(p+x)、Q(x)=den(p+x)，用 ComplexPolynomial::shift， 无求根），对 R(x)=q_m+q_{m+1}x+… 做幂级数除法 a_k = (p_k − Σ r_i·a_{k−i})/q_m（:341-352），得 Σ b_k/(s−p)^(m−k)。返回 [b_0…b_{m-1}]， b_0 乘 1/(s−p)^m（最奇异项）。只有 m≥2 才置 laurent = Some。

12  横向耦合矩阵组装

12.1 本章解决什么问题

把第 11 章的分类残差组装成 (N+2)×(N+2) 横向（transversal）耦合矩阵： N 条一阶支路并联在源/负载之间，无谐振器间耦合，只有 MSk、MkL、对角 Mk,k、 可选 MSL。这是综合链的终点、所有拓扑变换的起点。

12.2 入口与守卫

build_transversal_from_residues（synthesis/residues/transversal.rs:12-186）。

  • 维数守卫（:18-25）：三展开残差数各必须 == order，否则 DimensionMismatch。
  • 重复极点守卫（:27-37）：任一残差 laurent.is_some() ⇒ NotImplemented——横向链每个谐振器只表示一个简单极点， 1/(s−p)^m (m≥2) 不可表示。显式报错而非静默构造错矩阵。 （残差展开本身能处理重根、快路径能精确求和，但横向链不能——见第 11.5 节与附录 F。）
  • 分类（:48）：classify_residues(y11,y12,y22, 1e-6)。
  • 自适应极点轴容差（:55-58）： pole_axis_tolerance = max(1e-6, 1e-6·(N/5)²)——随阶数放大， 吸收 Durand-Kerner 精度退化 O(N²εmach)。order 5 ≈ 1e-6、order 20 ≈ 1.6e-5、order 30 ≈ 3.6e-5。

对每个分类（Real 单极点，或 ComplexPair 中逐个极点——不合并，见下）， 按 |r₁₁| ≥ |r₂₂| 选支路填一行（:60-157）：

若用 r₁₁：  MSk = |r₁₁|，  MkL = r₁₂|r₁₁| (12.1a)
否则：  MSk = r₁₂|r₂₂|，  MkL = |r₂₂| (12.1b)

对角：M[k,k] = −pole.im（= 实 ω 域失谐 Bk，[§4.6](#sec46)）。 对称写入：set(k,k,−pole.im)、set_symmetric(0,k,M_Sk)、set_symmetric(k,N+1,M_kL)。 源耦合恒为所用自残差的正平方根（恒正）；负载耦合携带 y12 的符号。

Real 路径（:63-103）：先验证 |pole.re| ≤ pole_axis_tolerance （否则 NumericalFailure），再 residue_real_component 提取 r₁₁/r₁₂/r₂₂ 实部， 按 (12.1) 填。ComplexPair 路径（:105-157）对两个极点各按同样的 (12.1) 独立填一行 （Cameron 2003 §III：每极占独立支路）。

偏差提示（dead helper） combine_conjugate_pair（:208-262，#[allow(dead_code)]）描述 "2·Re(r) 合并捷径"，但现行代码不加倍——ComplexPair 两极点各按 (12.1) 独立处理， 等效贡献是两条独立行之和。不要把这个 dead helper 当成已实现路径来描述。

12.4 直接源-负载耦合 M_SL

transversal.rs:159-184，两条来源：

  1. 若 y12.constant_term 存在（第 11.3 节长除常数）：其实部必须 ≤ 1e-6（否则报错——该路径下直接项必须纯虚），MSL = constant.im （|direct.im| > 1e-12 才写，:166）；
  2. 否则，当所有零点有限（transmission_zeros.len() == order，即无 ∞）时用闭式 MSL = ε·(εr − 1)/εr（:175-184）。

写对称 M[0,side-1] = M[side-1,0] = M_SL。

12.5 不变量与测试锚点

实现事实（回归/属性测试钉死）：order-4、±1.5 两零点、20 dB → 2 个 ComplexPair； 所有源耦合为正；M_Sk·M_kL 符号匹配 2·Re(r₁₂)；全矩阵对称到 1e-10。 nonzero_sqrt_abs（expansion.rs:426）拒绝 |残差| ≤ 1e-12。

拒绝 任一重复极点 → NotImplemented（不静默）；极点实部超自适应容差 → NumericalFailure； 直接项实部 > 1e-6 → error（非纯虚）。

12.6 复杂度

组装 O(N)（每极点 O(1) 写入）；分类 O(N²)（共轭配对最坏）；主导成本在上游求根（第 29 章）。 内存 O(N²)（矩阵本身）。

12.7 本章小结

横向矩阵 = 每极点一行：源耦合恒正（√自残差）、负载耦合带符号（r₁₂/√）、对角 = −pole.im； M_SL 来自长除常数或全有限闭式；重复极点显式 NotImplemented。 下一章用一个 4 阶算例把第 6–12 章整条链走通。

Part III

第三篇 · 拓扑变换

横向矩阵是"数学正确但物理不便"的形式（每条支路直连源和负载）。本篇章用正交相似变换 （保持响应不变）把它改写成折叠、箭头、级联三节/四节等可实现结构。

14  相似变换、Givens 旋转与响应不变量

14.1 本章解决什么问题

横向矩阵（第 12 章）每个谐振器都直连源和负载——N 条支路并联。这在物理上意味着 N 个谐振器全部同时接到输入/输出端口，无法用链式结构实现。工程上需要折叠 （相邻谐振器串联 + 跨接）或箭头（所有跨接集中到末端）等拓扑。 本章建立变换的数学基础（相似变换保持响应）与 O(N) Givens 旋转引擎。

14.2 正交相似变换保持响应

设 M 为耦合矩阵，R 为正交矩阵（R·Rᵀ = I）。定义变换后矩阵 M′ = R·M·Rᵀ（[§3.5](#sec35)，公式 (3.4)）。关键不变量：

  • 谱不变：M′ 与 M 同特征值（正交相似）；
  • 响应不变：A(ω) = M + ω·I_r − … 中只有 M 的耦合结构改变， 而 (3.3) 的 S₁₁/S₂₁ 只依赖 A⁻¹ 的 (0,0) 和 (n,0) 元素。 正交相似变换下 A(ω)′ = R·A(ω)·Rᵀ，故 A′⁻¹ = R·A⁻¹·Rᵀ， 其 (0,0) 和 (n,0) 元素在 R 只动谐振器行/列（不动端口行/列）时不变。

实现事实：库的 Givens 旋转只动两个谐振器 pivot（索引 ≥ 1），不碰端口行/列 0 和 N+1， 因此 (0,0)、(n,0) 元素精确不变，理想 S 参数逐点保持。 基准测试把不变性容差钉在 1e-10（tests/benchmark_standard.rs response_invariance 门）；CT/CQ 变换后 S21 幅度在 21 点网格上保持到 <1e-6 （docs/algorithms.md §6.4，有测试）。

14.3 O(N) 原地 Givens 旋转

apply_givens_similarity_inplace(pivot_a, pivot_b, cosine, sine) （matrix/core.rs:336-366）计算 M′ = R·M·Rᵀ， R 只非平凡于 2×2 块 {(p,p),(p,q),(q,p),(q,q)}（p=pivot_a, q=pivot_b）。 两步：

  1. 左乘 R·M（只动两行，core.rs:345-351）： row_a′ = cos·row_a − sin·row_b、row_b′ = sin·row_a + cos·row_b， 遍历 col in 0..side，O(N)；
  2. 右乘 M′·Rᵀ（只动两列，core.rs:358-364）： col_a″ = cos·col_a′ − sin·col_b′、col_b″ = sin·col_a′ + cos·col_b′， 遍历 row in 0..side，O(N)。

总计每次旋转 2·side 次乘加（零分配、原地），对比完整矩阵乘 O(N³)。 全库所有拓扑变换都走这条 O(N) 路径。 完整的 rotation_matrix_basic（rotations.rs:13-25）构造整个 R 矩阵但 dead-code-gated——活跃调用点全用原地版。

14.4 safe_angle 与 Jacobi 角

safe_angle(y, x)（rotations.rs:27-37）：计算旋转角以消去目标元素。 θ = atan(y/x)，但当 |x| < 1e-10 时返回 ±π/2（避免除以极小邻耦合）： y > 0 → −π/2、y < 0 → +π/2。符号约定（y > 0 → −π/2） 保证旋转把目标元清零。

diagonal_rotation_angle（rotations.rs:39-49）： Jacobi 角 θ = ½·safe_angle(2·M[a,b] / (M[b,b]−M[a,a]), 1)， 用于对角均衡（BOX 节、箭头对角目标）；对角差 |Δ| < 1e-10 时返回 0。

14.5 transform_matrix facade

transform_matrix(m, TopologyKind)（transform/mod.rs:64-115） 只做两件事：调 m.transform_topology（纯 match：Folded→to_folded、 Arrow→to_arrow、Wheel→to_arrow+改标签、Transversal→clone， core.rs:208-220）再附加模式校验（默认不附响应校验）。 transform_matrix_with_response_check 额外在网格上比较变换前后 S 参数。 实现事实：Wheel == Arrow（core.rs:224-227，弃用别名）。

14.6 本章小结

所有拓扑变换 = 正交相似变换（Givens 旋转），O(N) 原地实现，只动谐振器 pivot 不动端口， 因此理想响应逐点不变（基准 1e-10）。下一章给折叠拓扑的具体旋转序列。

15  折叠拓扑

15.1 本章解决什么问题

把横向矩阵（N 条支路并联）改写成折叠（folded）形式：谐振器链式串联 （主链 M[k,k+1]），跨接（cross-coupling）被 Givens 旋转"折"进链中。 折叠是物理实现最直接的拓扑（对应腔体滤波器的相邻耦合 + 隔腔耦合）。

15.2 to_folded 旋转序列

CouplingMatrix::to_folded（matrix/core.rs:381-440）。 设 end_oper = N/2（偶）或 (N−1)/2（奇）（core.rs:383-388）， 外层循环 row_oper_num in 0..end_oper，每层做列消去再行消去：

  1. 列消去（源耦合）（core.rs:392-409）：col 从 N−row_oper_num 降序到 row_oper_num+2。 若 |M[row_oper_num, col]| > 1e-7（阈值），在平面 (col−1, col) 做列操作， θ = safe_angle(−M[row,col], M[row,col−1])，消去 M[row,col]。 否则显式清零。净效果：保留 M[0,1]，消掉 M[0,k], k≥2。
  2. 行消去（负载耦合）（core.rs:411-428）：镜像列 col_oper_num = side−1−row_oper_num，row_in_col_oper 升序。 平面 (row, row+1)，θ = safe_angle(M[r,c], M[r+1,c])。
  3. 正主链符号规范（core.rs:431-438）：index in 0..side−1， 若 M[index,index+1] < 0 ⇒ flip_sign(index+1) （第 18 章），使最近邻主链耦合全正。
  4. clean_small_values()（≤1e-10 清零，core.rs:261-266）+ topology = Folded。

15.3 旋转几何

列消去本质：对源行（row 0）的每个远端耦合 M[0,k]，用 (k−1,k) 平面旋转把它"推"到 M[0,k−1]，迭代后所有源耦合集中到 M[0,1]。行消去是负载侧的镜像。 因为旋转是相似变换（[§14.2](#sec142)），每次旋转后 S 参数不变； 整个序列结束后矩阵变成"源只连 1 号、负载只连 N 号、谐振器链式串联"的折叠形。

15.4 响应不变性验证

实现事实：tests/benchmark_standard.rs 的 anchor_four_four_book_matrix_passes_the_invariance_gate、 anchor_six_three_… 把 Cameron 印刷的横向+折叠矩阵喂进 mfs 响应引擎， 断言折叠前后响应偏差 < 1e-10（ANCHOR_TOL）。 tests/folded_response_invariance.rs 对标准 6 个二端口案例做同样的不变性门。 to_folded 的回归测试（tests/synthesis_regression.rs assert_folded_transform_succeeds）验证变换成功 + 报告通过。

15.5 数值细节

  • 旋转阈值：1e-7（决定"旋转 vs 显式清零"，core.rs:393,412）； 清零阈值 1e-10。
  • 复杂度：O(N³) 次旋转（外层 ⌊N/2⌋ × 内层 ~N），每次 O(N) ⇒ 总 O(N³) 次乘加， 但常数小、零分配。对 N≤28 实测可接受（第 29 章高阶稳定性）。
  • 无收敛问题（确定性旋转序列）。

15.6 带通去归一化（scale）

denormalize_bandpass（matrix/scaling.rs:14-39）把归一化矩阵变成 物理频率：谐振器对角 value → denormalize_resonator_frequency(value, center, bw) （正频率支二次，scaling.rs:128-131，review P1-2 修正——历史形式取负频率支、 镜像所有失谐符号）；端口对角置 0；非对角 × bandwidth_hz。 denormalize_bandpass_with_external_q（:47-67）额外把端口耦合换成 外部 Q：Qe = 1/(M²·Δ)（Δ=相对带宽，scaling.rs:152-161， 约定由 order-1 带通物理测量锚定），拒绝 |M| ≤ 1e-12。

15.7 边界与失败模式

注意 to_folded 本身不返回 error（确定性旋转），但输入矩阵若不对称 （经 new_with_topology_asymmetric）可能破坏旋转假设——构造端有对称守卫兜底（[§3.4](#sec34)）。 safe_angle 的 1e-10 门防止除以零。

15.8 本章小结

折叠 = 列消去(源) + 行消去(负载) + 正主链符号，全用 O(N) Givens 相似旋转，响应不变(1e-10)。 去归一化用正频率支二次 + 外部 Q = 1/(M²Δ)。下一章箭头拓扑。

16  箭头拓扑

16.1 本章解决什么问题

箭头（arrow）拓扑把所有跨接耦合"聚到最后一个谐振器列"，形成首行简化的箭头形。 它是 CT/CQ 级联综合的前置形式（[§17](#ch17) 都先转箭头）。 与折叠不同，箭头不做正主链符号规范。

16.2 to_arrow 旋转序列

CouplingMatrix::to_arrow（matrix/core.rs:442-467）： 对 resonator in 1..N、target in (resonator+1)..=N， 平面 (resonator, target)，把每个谐振器到更高号谐振器的耦合 聚到最后一个谐振器列（箭头形）：

  • target_index = resonator−1、pivot_a = resonator、pivot_b = target、sign = −1；
  • 若 target_index ≠ pivot_a（非对角目标）：θ = safe_angle(−M[target_index][pivot_b], M[target_index][pivot_a]) ——消去 M[target_index][pivot_b]；
  • 否则（对角目标，target_index == pivot_a）：θ = diagonal_rotation_angle(matrix, pivot_a, pivot_b) （Jacobi 对角旋转）；
  • 应用 O(N) Givens 相似旋转（原地）。

无条件旋转：已 ≈0 时 θ≈0 为 no-op；无正主链符号阶段（与折叠的区别）。 收尾 clean_small_values() + topology = Arrow。

16.3 Wheel 别名

实现事实：Wheel 拓扑已弃用，当前是 Arrow 的别名—— transform_topology 对 Wheel 调 to_arrow() 再改标签 （core.rs:224-227）。不要为 Wheel 单独设计算法。

16.4 响应不变性

与折叠同：正交相似变换，响应不变（1e-10 门）。箭头是 CT/CQ 的中间形式， extract_trisection 要求输入 topology == Arrow （sections.rs:101-105，否则 PreconditionViolation）。 测试 trisection_extraction_rejects_non_arrow_input（matrix/mod.rs:230）钉死该前置。

16.5 本章小结

箭头 = 把跨接聚到末列的旋转序列，无条件旋转、无符号规范；Wheel 是弃用别名。 箭头是 CT/CQ 的前置。下一章级联三节/四节。

17  CT/CQ 拓扑

17.1 本章解决什么问题

级联三节（Cascaded Trisection, CT）与级联四节（Cascaded Quadruplet, CQ） 把矩阵分解成可独立综合的"节"（section），每节对应一对/一个传输零点。 这是实现复杂跨接拓扑（如 Cameron 2011 Fig. 21 的 4-2 不对称三节）的标准路径。 两条路径都先转 Arrow，再抽取。

17.2 CT：Cascaded Trisection

to_cascaded_trisections(zeros)（matrix/cascade.rs:28-51）：

  • 守卫：zeros 非空（:30-33）；order ≥ zeros.len()+2 （:39-46，写成 order < zeros.len()+2 以避免 order=1 的 usize 下溢， review P2-1；测试 ct_zero_guard_order1_returns_error_not_panic）。

18  符号翻转、结构约束与失败条件

18.1 本章解决什么问题

拓扑变换反复用到一个共享原语——相似度符号翻转 flip_sign_inplace（整行+整列取负，对角不变）。它是折叠正主链规范与 CT/CQ 收尾共用的"符号规约"。本章固定它的正确性不变量（历史上因对角被取负第三次而丢传输零点）， 并汇总第三篇的结构约束与失败条件。

18.2 flip_sign_inplace 与对角不变量

flip_sign_inplace(index)（matrix/mod.rs:30-44）： 对谐振器 index 做 R·M·Rᵀ（R[index][index]=−1）： 整行取负 + 整列取负。对角元被取负两次（行一次、列一次）⇒ 净不变。

关键正确性不变量 绝不能取负第三次。历史 bug：偶数阶非对称滤波器对角被多取负一次， 翻转自耦合符号、丢传输零点（docs/folded-fidelity-flip-sign-fix.md）。 回归测试 flip_sign_negates_row_and_column_only_and_preserves_diagonal （core.rs:642）钉死：对角不变 / 仅行列变号 / 两种形式（不可变 flip_sign = clone + 共享原语，core.rs:375-379）逐位一致 / 双翻为恒等。

共享原语的两个消费者：折叠的 flip_sign（不可变包装）与 ensure_positive_main_couplings（CT/CQ 收尾，sections.rs:283-290） 直接调它。两者用同一符号规约：index in 0..side−1，M[index,index+1] < 0 ⇒ flip_sign_inplace(index+1)。

19  基于矩阵的 LU 响应计算

19.1 本章解决什么问题

给定耦合矩阵 M 与频率网格，逐点算 S₁₁、S₂₁、群延迟。LU 路径是权威参考： 对所有拓扑（Transversal/Folded/Arrow/CT/CQ）与有耗（Q 有限）情形都正确， 因此用作快路径的校验基准。本章给 A(ω) 构造、选择性求解与群延迟公式。

19.2 A(ω) 构造

每个频率点（src/response/backend.rs，evaluate_response）构造复响应矩阵：

A(ω) = M + ω·Ir − jRS·e₀e₀ᵀ − jRL·eₙeₙᵀ (19.1)

Ir 只在谐振器对角（1…N）为 1，端口对角为 0。 有耗（Qu 有限）时谐振器对角再 − j/Qu （backend.rs:130-138，把极点移出虚轴，避免虚轴奇异）。

19.3 选择性求解（一次 LU 解两个右端）

S 参数只需要 A⁻¹ 的两个元素：(0,0) 与 (n,0)（[§3.3](#sec33) (3.3)）。 实现事实（backend.rs:172-194）：不做完整求逆—— 只解 A x = e₀（第一列）与 A y = eₙ（最后一列）， 一次 LU 分解解两个右端，省掉完整求逆的 N−2 次回代。 A 对称 ⇒ 最后一行 = 最后一列，故 (n,0) 元素从 A⁻¹ 的 (n,0) 位置读出。

S₁₁ = 1 + 2jRS[A⁻¹]₀₀,    S₂₁ = −2j√(RSRL)[A⁻¹]n,0 (19.2)

19.4 LU 群延迟

群延迟（第 22 章定义）在 LU 路径的解析形式（backend.rs:164-169 区域）：

τ = Im( Σk [A⁻¹]n,k·[A⁻¹]k,0[A⁻¹]n,0 ) = −Im( d/dω ln S₂₁ ) (19.3)

即对 ln S₂₁ 关于归一化 ω 求导取负虚部。 实现事实：LU 群延迟利用对称取"最后一行 = 最后一列"（backend.rs:164-169）， 但消费端不验证对称——若经 new_with_topology_asymmetric / allow_asymmetric(true) 喂入非对称矩阵，S₁₁/S₂₁ 幅度仍对、 群延迟会静默算错（review 0.6.1 P1-3）。构造端现在有对称守卫兜底，但这是已知不变量（[§19.5](#sec195)）。

19.5 已知限制

对称依赖 LU 路径的 S₁₁/S₂₁ 幅度对对称性不敏感（只读 A⁻¹ 的 (0,0)、(n,0)），但群延迟公式 (19.3) 用了"最后一行=最后一列"的对称假设。非对称输入（opt-out 构造）群延迟静默错、幅度不受影响。 这是 review 记录的已知不变量，不是 bug——构造端的对称守卫是兜底。

19.6 入口与单位

ResponseSolver::evaluate_normalized(_with_settings) （response/mod.rs:169-185）直接吃归一化网格； evaluate(_with_settings)（:142-166）先经 mapping.map_grid_hz_to_normalized 把物理网格映成归一化 ω（[§2](#ch2)）再逐点求解。 ResponseSettings（:120-138）：source_resistance、 load_resistance（默认 1）、unloaded_q（默认 ∞ = 无耗）。 群延迟单位：归一化 dτ/dω（[§22.1](#sec221)）。

19.7 复杂度

每频率点：构造 A(ω) O(N²)（复数化）+ 一次 LU 分解 O(N³) + 两次回代 O(N²)。 逐点 O(N³)——这是快路径（第 20 章 O(N)）要替代的成本。 预处理无（每点独立）。内存 O(N²)（复矩阵）。

19.8 本章小结

LU = A(ω) 构造 + 一次分解解两个右端（e₀、eₙ）→ S₁₁/S₂₁ + 解析群延迟 (19.3)。 权威、全拓扑通用、支持有耗，但逐点 O(N³)。群延迟依赖对称（已知不变量）。 下一章 O(N) 极点展开快路径。

20  极点展开快路径

20.1 本章解决什么问题

横向矩阵的 S 参数可以解析地写成极点的部分分式，从而把每点 O(N³) 的 LU 降到 O(N)。这是快路径（fast path）：PoleExpansionData 从横向矩阵 直接读极点/残差（不求根），逐点用 Schur 2×2 补矩阵解析求 S 参数 + 群延迟。 本章给极点/残差的读取、Schur 求值、Laurent 求和与近奇异守卫。

20.2 从矩阵直接读极点与残差

PoleExpansionData::from_matrix（src/response/pole_expansion.rs:79-148）。 前置：assert_transversal_structure（:152-207）—— 谐振器块 M[1..=N][1..=N] 必须对角、端口对角 M[0,0]=M[N+1,N+1]=0 （容差 1e-9·max(|M|,1)，:158）。非横向/端口短路 → PreconditionViolation。

对 k in 1..=N（:96-110），不求根，直接读：

量读法物理含义
极点 pole_k−M[k,k]（= −Bk，实 ω 域）失谐量
残差 y11M[0,k]² = MSk²源自耦合平方
残差 y12M[0,k]·M[k,N+1] = MSk·MkL传输残差
残差 y22M[k,N+1]² = MkL²负载自耦合平方
常项 y12M[0,N+1] = MSL直接源-负载耦合

极点域约定（review P2-12，:73,81-84）：存的是实 ω 域极点 −Bk， evaluate_at 用实 ω 组 denom = ω − pole（与 [§4.6](#sec46) 一致）。 source_r = load_r = 1.0（:121-122）。

20.3 evaluate_at：Schur 2×2 解析求值

evaluate_at(ω)（pole_expansion.rs:233-339，私有），返回 (S11, S21, group_delay)，O(N)/点。 算法（对谐振器块 D = diag(jω+B_k) 做 Schur 2×2 补）：

  1. 单遍遍历极点（:263-300），累加三个 Y 的部分分式： Σ r₁₁/(ω−pole_k)、Σ r₁₂/(ω−pole_k)、Σ r₂₂/(ω−pole_k)， 以及各自的 ω 导数（群延迟用）。 denom.norm_sqr() > 1e-30 才累加（:267，近零分母跳过）。
  2. 组 Schur 2×2（:303-306）： s00 = −jR_S − Σ₁₁、s01 = M_SL − Σ₁₂（对称 s10 = s01）、 s11 = −jR_L − Σ₂₂；ω 导数 ds00 = −ds₁₁ 等（:309-310）。
  3. 近奇异守卫（:314-320）：det = s00·s11 − s01·s10， 若 det.norm_sqr() ≤ 1e-30 → NumericalFailure("pole expansion: near-singular Schur determinant")——防止伪造 (1,0) 全反射样本（review P3 #1）。
  4. 解析求逆：inv_00 = s11/det、inv_10 = −s10/det（:323-324）。
  5. S 参数：S11 = 1 + 2j·R_S·inv_00、 S21 = −2j·√(R_S·R_L)·inv_10（:327-329）。 与 LU 的 (19.2) 同式，只是 A⁻¹ 的元素用 Schur 解析算了。
  6. 群延迟（:333-339）： ddet = ds00·s11 + s00·ds11 − 2·s01·ds01； inv_10.norm_sqr() ≤ 1e-18 → None（传输零点，显式未定义）； 否则 Some(−(ds01/s01 − ddet/det).im)。 与 LU 用同一 1e-18 阈值。

20.4 Laurent 求和与导数（重根）

若某极点带 Laurent 主部（第 11 章，laurent = Some），快路径用自己的 Laurent 长度精确求和（每个 Y 独立长度，[§11.4](#sec114)）：

求和 laurent_sum（:356-371）： b₀/denom^m + b₁/denom^{m-1} + … + b_{m-1}/denom （累加 1/denom, 1/denom², …, 1/denom^m 再反转，使索引 k 持 1/denom^{m-k}）。

导数 laurent_derivative（:343-351）： d/dω Σ_k b_k/(jω−p)^{m−k} = −j·Σ_k (m−k)·b_k/(jω−p)^{m−k+1} （代码用 denom.powi(power+1)，denom 已含 jω 形式）。

简单极点（laurent = None）的导数：d/dω[r/(ω−p)] = −r/(ω−p)²。

20.5 群延迟在传输零点

实现事实：在传输零点（S₂₁→0），群延迟返回 None （inv_10.norm_sqr() ≤ 1e-18，:247,336），与 LU 的退化守卫一致—— 显式未定义，不是假 0。这与 ResponseSample.group_delay: Option<f64> 的约定一致（[§22.4](#sec224)：只在数值退化处 None，从不静默 0.0）。

20.6 对外入口

evaluate_normalized(grid)（:377-394）：逐点 evaluate_at； 任一点近奇异 → typed error（调用方落回 LU）。 evaluate_bandpass(grid, mapping)（:399-420）：物理 Hz 先经 mapping.map_hz_to_normalized 映成 ω 再 evaluate_at。

20.7 复杂度与适用

预处理 O(N)（读极点/残差）；逐点 O(N)（单遍求和 + 2×2 求逆）。 对比 LU 逐点 O(N³)。仅适用无耗横向矩阵（前置断言）； 有耗（Q 有限）或非横向 → 前置失败 → 落回 LU（第 21 章信任策略）。

20.8 边界与失败模式

拒绝 / 退化 非横向结构或端口短路 → PreconditionViolation（前置）； 近奇异 Schur 行列式 → NumericalFailure（该点落回 LU）； 传输零点群延迟 → None（显式未定义）。

20.9 本章小结

快路径 = 从横向矩阵直接读极点(−B_k)/残差(M_Sk², M_SkM_kL, M_kL²) + M_SL， Schur 2×2 解析求逆 → S₁₁/S₂₁ + 解析群延迟，O(N)/点，重根用各自 Laurent 长度精确求和。 仅无耗横向适用。下一章信任策略与验证门如何决定"用快路径还是 LU"。

21  快路径输入契约、验证门与 LU 回退

21.1 本章解决什么问题

快路径在数值上对某些输入不可靠（近网络极点、非横向矩阵）。 库用一个信任策略决定何时用快路径、何时落回 LU：先在 5 点检查网格上 把快路径与 LU 比对，通过验证门才信任快路径算全网格； 信任后单点近奇异仍逐点落回 LU。本章给门的全部逻辑与阈值。

21.2 输入契约

快路径的结构前置（assert_transversal_structure，[§20.2](#sec202)）： 矩阵必须是横向（谐振器块对角、端口对角零）。非 Transversal 标签的矩阵 （Folded/Arrow/CT/CQ）也被前置拒绝——response_normalized 文档 （design.rs:485-486）明确："非横向存储矩阵被快路径结构前置 upfront 拒绝， 改由 LU 评估"。注意这是结构检查（看数值布局），不是看 topology 标签。

21.3 验证门 fast_path_gate

fast_path_gate(pole, lu)（src/design.rs:72-105）， 产物 GateVerdict{compared, max_diff, all_finite}（:40-59）：

  • 逐检查点对比复数 S₂₁（幅度和相位）与 S₁₁，不只 |S₂₁|—— 一个丢/错符号耦合若只让 |S₂₁| 几乎不变而旋转相位，或只动 S₁₁，会溜过纯幅度门 （round-3 review 修正）；
  • 每点：若 l.s21_mag() ≤ FAST_PATH_GATE_S21_FLOOR (= 1e-10) （design.rs:37）→ 跳过（深阻带点，无可比对象）；否则 compared += 1；
  • 非有限检查：任一比较值非有限 → all_finite = false（该点自动门失败， 不是"大但有限的偏差"）；
  • max_diff = max(max_diff, |(p21−l21)/l21|, |(p11−l11)/l11|)（复数模）。

通过条件（GateVerdict::passes(tol)，:56-58）： compared > 0 && all_finite && max_diff < tol。 调用点用 tol = 1e-3（design.rs:519,620）。

21.4 信任策略主流程

response_normalized（design.rs:489-530）：

  1. grid = linspace(start, stop, points)；
  2. PoleExpansionData::from_matrix(&matrix)—— Err（非横向/端口短路）→ 跳过快路径，直接 LU 全网格（:529）；
  3. 5 点检查网格：check_grid = linspace(start, stop, 5.min(points))（:505）；
  4. lu_check = ResponseSolver.evaluate_normalized(matrix, check_grid)（:506）；
  5. pole_check = pole_data.evaluate_normalized(check_grid)—— Err（某点近奇异）→ 直接 LU 全网格（:509）；
  6. verdict = fast_path_gate(pole_check.samples, lu_check.samples)（:518）；
  7. 若 verdict.passes(1e-3)（:519）： return pole_data.evaluate_normalized(grid).or_else(|_| LU(grid))（:522-524）—— 快路径算全网格，单点近奇异仍逐点落回 LU；
  8. 否则：LU 全网格（:529）。

response_bandpass（design.rs:586-643）是同一逻辑在物理网格上 （n_check = 5.min(points)，经 mapping 映射）。

21.5 为什么是 5 点 + 1e-3 + 复数比较

  • 5 点：足够采样通带/带边/阻带的代表性点，又便宜（一次 5 点 LU 检查）。 5.min(points) 处理小网格。
  • 1e-3 相对偏差：快路径与 LU 都是同一物理网络的两种算法； 1e-3 容许舍入/条件差异，但抓住结构性错误（丢耦合、错符号、相位翻转）。
  • 复数比较（幅度+相位+S₁₁）：纯幅度门会被"幅度不变但相位旋转"的错答案骗过 （round-3 review 明确修正）。
  • 非有限即失败：NaN/Inf 不是"大偏差"而是自动门失败，防静默 NaN 答案。

21.6 复杂度

信任检查：5 点 × (LU O(N³) + 快路径 O(N)) = O(N³) 一次性成本（常数 5）。 通过后全网格 O(N)×点数。最坏（门失败）全网格 O(N³)×点数。 预处理（信任检查）与逐点成本分离——这是"复杂度须注明前提"的实例。

21.7 边界与失败模式

回退语义 任何环节失败（前置 Err、检查 Err、门失败、单点近奇异）都落回 LU而非报错—— 响应总是返回（LU 是权威），只是可能慢。真正向调用方报错的只有 LU 本身失败 （如矩阵病态到 LU 也解不出）。

21.8 本章小结

信任策略 = 结构前置(横向) + 5 点 LU 交叉检查 + 复数门(1e-3, 非有限即失败) → 通过则快路径全网格(单点近奇异逐点落回 LU)，否则全 LU。 这保证"快路径只在被验证时信任"。下一章群延迟的定义与独立验证。

22  群延迟：定义、解析计算与独立验证

22.1 本章解决什么问题

群延迟 τ = −dφ/d(2πf) 是滤波器相位响应的斜率，决定脉冲展宽与 信号失真。MFS 在两条求解路径（LU、极点展开）都解析计算群延迟， 单位是归一化原型 dτ/dω。本章固定定义、两条路径的公式、 单位换算（含 2π 陷阱）与独立验证方法。

22.2 定义与归一化单位

物理群延迟 τ = −dφ/d(2πf)（φ 是 S₂₁ 相位，f 物理频率）。 MFS 的 group_delay 字段是归一化单位 dτ/dω（ω = normalized_omega，[§2](#ch2)），即

GD ≡ −Im( d/dω ln S₂₁ ) (22.1)

两条路径同单位（response/mod.rs:15-20）。 不是"每赫兹"也不是"每弧度角频率"。 实现事实：LU 用 (19.3)、极点展开用 [§20.3](#sec203) 第 6 步， 都算 (22.1)。

22.3 换算成秒与 2π 陷阱

物理群延迟（秒）由链式法则： dτ/d(2πf) = (dτ/dω)·(dω/d(2πf))。 对带通映射 ω = (1/FB)(f/fc − fc/f) （[§2.4](#sec24) (2.2)），dω/df = (1/FB)(1/fc + fc/f²)，故

τ[秒] = GD·1FB (1fc + fcf²)·12π (22.2)
2π 陷阱（2026-10-11 记录，response/mod.rs:26-33） 数值 −d(phase)/df 参考是"每赫兹"，比"每秒"大 2π 倍。 直接和秒值比会读出 (2π−1)·gd ≈ 85 ns 的假偏差。 判据：该偏移随 |S₂₁| 增大、细化网格不缩小—— 指向单位/约定错配而非算法 bug（截断误差会随网格细化缩小）。 对比时先乘 dω/df 或除以 2π。

22.4 None 语义

group_delay: Option<f64> 只在数值退化处（传输零点 S₂₁→0、 近奇异分母）返回 None，从不静默 0.0 （response/mod.rs:34-35）。两条路径用同一守卫 norm_sqr() ≤ 1e-18（LU backend.rs、 极点展开 pole_expansion.rs:247,336）。 物理含义：在传输零点 S₂₁ 相位不连续（绕 ±π），群延迟发散/未定义， 故显式 None 而非给一个假数。

22.5 独立验证

群延迟有三层独立验证：

  • 跨路径一致性：LU 与极点展开在相同网格算出的群延迟应一致 （tests/response/mod.rs 测试钉死跨后端群延迟一致性， 容差见 [§32](#ch32)）；
  • 独立数值微分基准：用中心差分 −(φ(ω+h)−φ(ω−h))/(2h) （经 (22.2) 换算成秒，注意 2π）对照解析值，独立于两条解析路径；
  • None 契约：传输零点处必须 None（不是 0），由测试钉死。

实现事实：review round-3（P2-1）记录了群延迟独立锚点覆盖的补全—— 此前只有跨路径一致性，现加了独立数值微分基准，防止"两条路径同错"。

22.6 群延迟在传输零点附近的行为

接近（但不等于）传输零点时，S₂₁ 相位快速绕变，群延迟出现尖锐峰/谷 （Lorentz 型），数值上对 ω 敏感。这是物理现象（极点-零点对的群延迟特征）， 不是算法错误。库的处理：精确零点 → None；近零点 → 给出大但有限的值 （由解析导数稳定计算）。不要把近零点的大群延迟当 bug"平滑"掉。

22.7 本章小结

群延迟 = −Im(d/dω ln S₂₁)，归一化单位，两条路径同单位、同 None 守卫(1e-18)。 换算成秒用 (22.2)，警惕 2π 陷阱。独立验证 = 跨路径 + 数值微分 + None 契约。 下一章 Touchstone I/O 与端口约定。

23  Touchstone 数据及端口约定

23.1 本章解决什么问题

Touchstone（.s2p）是射频行业标准的 S 参数文件格式。MFS 提供导出/导入， 以及基于 touchstone crate 0.14.5 的活动网络操作 （重采样、Y/Z/ABCD 转换、级联）。本章给格式约定、端口约定与网络操作。

23.2 格式约定

src/touchstone.rs 支持：

  • 版本：v1.0 / v2.0；

build_network(response, z0) / FilterDesign::build_network() （0.5.0 引入）：从响应样本构建一个活动的对称互易 2 端口 touchstone::Network（经 crate 的 NetworkBuilder）， 支持重采样、Y-Z-ABCD 转换、保存/检视。 这是"活网络"接口——可在 mfs 外部用 touchstone crate 的完整工具链继续处理。

23.6 本章小结

Touchstone = 行业 S 参数文本格式，MFS 支持 v1/v2、RI/MA/DB、Hz…GHz、可配阻抗。 端口约定与第 3 章一致。build_network 给出活动 touchstone::Network。 下一章网络级 cascade（级联两个 2 端口）。

24  网络级 cascade

24.1 本章解决什么问题

把两个 2 端口网络级联（cascade）成一个 2 端口网络（端口 2→端口 1 连接）， 用于多节滤波器串联、或把综合出的网络与外部网络组合。 基于 touchstone crate 的 ABCD 级联，MFS 在其上加类型化前置校验。

24.2 cascade 前置校验

touchstone::cascade(a, b) / FilterDesign::cascade(&other) （0.5.0，src/touchstone.rs）在调用 crate 的 Network::cascade （ABCD 级联）之前预校验，返回 MfsError 而非继承上游 panic 或静默逐索引网格配对：

  • 秩：两个网络都必须是 2 端口；
  • 参考阻抗：z0 一致（否则 ABCD 级联的物理意义不对）；
  • 频率单位：一致；
  • 频率网格：逐点相同（级联要求同网格）。

任一校验失败 → typed MfsError（具体变体按失败项）。 这是"把上游 panic/静默配对转成类型化错误"策略的实例（[§23.5](#sec235)）。

24.3 ABCD 级联数学

级联用链矩阵（ABCD/传输矩阵）：每个 2 端口由 ABCD 矩阵描述， 级联 = 两个 ABCD 矩阵相乘（[A B; C D]_total = [A B; C D]_a · [A B; C D]_b， 端口 2 of a → 端口 1 of b）。再由总 ABCD 转回 S 参数（参考阻抗一致时）。 touchstone crate 0.14+ 提供 Network::cascade 实现此转换； MFS 不重复实现，只做前置校验 + 错误包装。

边界 cascade 要求两网络同网格/同单位/同 z0。若需不同网格级联，先对其中之一重采样 （经 build_network 得到的活动网络支持重采样，[§23.4](#sec234)）使其同网格，再 cascade。

24.4 与综合矩阵的关系

cascade 是网络级操作（在 S/ABCD 域），区别于第 17 章的矩阵级 CT/CQ 级联综合（在耦合矩阵域、保持响应的相似变换）。两者不同： 前者把两个独立网络串成一个大网络（响应是真正的级联响应）； 后者把一个网络重排成级联节结构（响应不变）。不要混淆。

24.5 本章小结

网络级 cascade = 两 2 端口经 ABCD 串成一个大 2 端口，前置校验秩/z0/单位/同网格， 失败走 typed error。与矩阵级 CT/CQ（相似变换、响应不变）是不同层面的"级联"。 第四篇结束；第五篇高级综合（双工器/多工器/多频带/优化）。

25  双工器与多工器

25.1 本章解决什么问题

双工器（duplexer）= 两个带通信道（Tx/Rx）共享一个公共天线端口； 多工器（multiplexer）= N 个信道共享一个公共 junction。 核心难点是信道间互载（mutual loading）：一个信道的存在改变另一个的响应。 MFS 提供两条路径：简化频移微扰（默认，相邻信道保真度有限）与 全谱 Macchiarella–Tamiazzo 迭代（full_iteration(true)，收敛且门锚定）。 两路径共享同一核心（synthesis/machiarella.rs）——双工器是 N=2 特例， 与历史双工器循环逐位一致。

25.2 数据结构与 junction 类型

ChannelSpec（duplexer.rs:175-187）：每信道 order、return_loss_db、zeros、center_hz、bandwidth_hz。

JunctionType（duplexer.rs:155-171），T 型 junction 模型：

  • TypeI { n, b0 }：波导 H 面，变压器比 n、电纳 b0。 理想 Type-I = {n:1.0, b0:0.0}（默认）；
  • TypeII { c0 }：同轴节点，电容 c0（在 s = 1/c0 加一个实反射零点）。

Duplexer（:15-20）= 两个 FilterDesign（Tx, Rx）； DuplexerResponse（:24-40）= 3 端口 S 参数（dB）： tx_s21_db、rx_s21_db、tx_s11_db、rx_s11_db、 antenna_s11_db、isolation_db。

响应近似（Duplexer::response，:64-118）： Tx/Rx 各自经自己的 BandPassMapping 独立评估； 天线反射 ≈ 几何均值 √(|S₁₁_tx|·|S₁₁_rx|)（理想 T 型近似）； 隔离度 ≈ |S₂₁_tx|·|S₂₁_rx|（线性，两信道传输之积）。 全部经 magnitude_to_db 转 dB。

25.3 简化频移微扰路径（默认）

DuplexerSynthesis / MultiplexerSynthesis 的默认路径： 独立综合每信道，再做频移微扰迭代近似互载。 已知限制（docs/architecture.md Known Limitations #4）： 相邻信道保真度有限——对充分分离的带不收敛到机器容差， 被加载信道丢失部分带内峰。全谱路径（下一章）解决此问题。

多工器分析（Multiplexer）提供 (N+1) 端口： response、channel、channel_folded、channel_matrices （architecture.md multiplexer 节）。测试 （tests/multiplexer.rs）验证：N=2 与双工器逐位一致（中心恢复 <1 MHz）、 N=3/4 综合成功、(N+1) 端口形状、公共口带内平坦（≤0.5 dB）、信道隔离（≤0.5 dB）。

25.4 full_iteration(true) 入口

DuplexerSynthesis::full_iteration(true) / MultiplexerSynthesis::full_iteration(true) 切换全谱路径， 走 synthesis/machiarella.rs 的共享循环。 支持范围（门锚定，architecture.md #4）：

  • Type-I 阶 2–8 + Type-II（含 §VI 40 阶 GSM 设计）：收敛、门锚定（2026-10-03）；
  • N=3/4 三工器/四工器：收敛、0 dB 带内、准等纹波天线 RL、para-identity（2026-10-04, B2）；
  • N>2 仅支持理想 Type-I（n=1, b0=0）与 Type-II—— 非理想 Type-I 且 N>2 被 PreconditionViolation 拒绝 （"无论文依据不臆造数学"，machiarella.rs:196-214）。

下一章给全谱迭代的完整数学。

双工器 = N=2 多工器特例；共享公共 junction 天线口。两条路径：简化频移微扰（默认、相邻保真有限） 与全谱 M–T 迭代（full_iteration(true)、收敛门锚定）。响应用理想 T 型几何均值/传输积近似。 N>2 只支持理想 Type-I 与 Type-II。下一章全谱迭代数学。

26  全谱路径、谱分解与迭代

26.1 本章解决什么问题

Macchiarella–Tamiazzo（M–T）全谱迭代是 N 信道共享 junction 的严格综合： 把 N 个信道耦合到一个公共 junction，求解信道间互载的固定点。 本章给公共带通域构造、固定分子 N、p₀² 解、谱密度 R、谱因子 D、 ∏S 关系、根分配与收敛判据——即 run_full_iteration（machiarella.rs:510-708） 的完整算法。

26.2 公共带通域（common band-pass domain）

prepare（machiarella.rs:182-339）。单变量 s = j·Ω(f)，Ω(f) = (f/f₀ − f₀/f)/b， f₀ = √(f_L·f_H)、b = (f_H−f_L)/f₀ 取最外侧两通道的边， 使两个极端边落在 s = ±j（:226-243）。 每信道原型 P_p(ω) 经仿射 P_c(Ω) = P_p(AᵢΩ + Bᵢ) 合成到公共域 （:245-255）：

Aᵢ = Ωᵢ,hi − Ωᵢ,lo2,    Bᵢ = Ωᵢ,hi + Ωᵢ,lo2 (26.1)

外围边选择（:257-294）：每信道取离其他信道中心最远的带边（平手取下边）。 N=2 时恰为 ±j（与历史逐位一致）；N≥3 时 s = j·ω(f_edge)（不一定 ±j）。

26.3 固定分子 N 与初始 S

固定分子 N(Ω)（:277-306，循环外建一次）： 所有信道反射零点（各 F 的根，原型虚轴）映到公共域 j·(Bᵢ + Aᵢ·r.im)；Type-II 额外加实零点 1/c0。

初始 S 状态（:321-339）：Sᵢ = (Eᵢ + pad(Fᵢ, deg Eᵢ))/2 （单带综合的左半平面特征多项式）。

26.4 每迭代步骤（run_full_iteration）

对每次迭代 k（:548-702）：

  1. 原型 → 公共域（:557-567）：Sᵢ(Ω)、Pᵢ(Ω) 经 (26.1) 仿射映射；
  2. 传输多项式（:569-580）： Ptᵢ = Pᵢ·∏_{j≠i} Sⱼ（信道 i 的传输 = 自己的 P 乘所有别的信道的 S）；
  3. p₀² 解（ solve_p0，:347-433）：在每信道外围边 eᵢ 列 RL 条件 Σⱼ |Ptⱼ(eᵢ)|²·p0ⱼ² = |N(eᵢ)|²·(1−εᵢ)/εᵢ，εᵢ = 10^(−rlᵢ/10)。 N=2 用 Cramer 规则逐位一致（det |·| < 1e-30 → 均分； p0² < −1e-12 → typed 拒绝"通道强耦合/重叠"； (−1e-12, 0] 当舍入、地板到 P0_SQ_FLOOR = 1e-15 保证 sqrt 良定义）。 N≥3 用 nalgebra LU 部分主元（失败 → NumericalFailure("p₀² system is singular")）；
  4. 谱密度（:576-590）： R = N·Ñ + Σᵢ p0ᵢ²·Ptᵢ·Pt̃ᵢ（~= alternating_conjugate）。 在虚轴 R(jω) ≥ 0 ⇒ para-identity D·D̃ = R，D 为 LHP 谱因子；
  5. 谱因子：D = spectral_factor(R, deg N)（第 26.6 节）；
  6. ∏S（compute_s_product，:438-474）： Type-I (a·N + b·D)/2（理想 a=b=1 ⇒ (N+D)/2， junction 关系 N + D = 2·∏S）； Type-II (c0/2)(D_monic − N)（D 领先项与 N 抵消，留 (2/c0)·∏S）。 D 先 re-monic（spectral_factor 只修相位不修幅值）； |lead| < 1e-15 → NumericalFailure（避免 200 次迭代缩放灾难）；
  7. 根分配 assign_blocks（:476-505）：∏Sᵢ 的根按 (imag, real) 升序，取连续块（块大小 nᵢ，按通道中心升序）；映回原型 （to_proto 丢弃非有限与 |r|≥50）；丢根 → typed NumericalFailure 指名越界根；
  8. 收敛（:637-690）：max_delta = 各信道对齐根位移最大值； 接受当 max_delta < tol（严格）或（高阶停滞） 迭代 ≥5 且连续 3 次不改善且 best_delta < 1e-3 （STAGNATION_MIN_ITER=5、STAGNATION_WINDOW=3、 STAGNATION_ACCEPT=1e-3，:136-138）。
一次性捕获滞后（§C.5） 返回的 common.{d, pt, p0_sq} 描述第 k 次迭代，而 s_roots 是 k+1； 滞后被报告的 convergence_error 界定，有意不重算 （重算会改变收敛行为）（:651-665）。

26.5 junction_response

junction_response(common, channel_count, start, stop, points) （machiarella.rs:743-804）：扫 S_ant = N/D、 Sᵢ = √p0ᵢ·Ptᵢ/D（在 s = jΩ(f)）。 守卫：|D| < 1e-300 → NumericalFailure("junction response: D vanishes on the sweep")。

26.6 谱分解 spectral_factor

src/spectral.rs。问题：给定 para-Hermitian R(s) （R(jω) ≥ 0），求度 = target、全左半平面的 D(s) 使 R = D·D̃。spectral_factor（:384-415）调度：

  1. 先 cepstrum（:33-118，无求根，O(N log N)）： FFT 大小 next_pow2(max(8·deg, 128))；在 ω∈[−ω_max,ω_max] 直采 |R(jω)|、log（地板 −690 = ln 1e-300， 阈值 1e-300）；IFFT → 实 cepstrum； 最小相位窗（causal 半保留，Nyquist 与 cep[0] 各半）； 前向 FFT → log D(jω) → exp；系数恢复用最小二乘 （Vandermonde 法方程 LU，在良好条件子集，fit_polynomial_from_freq_samples :135-188，奇异 → NumericalFailure）；
  2. para_product_verified 不过则退回平衡伴随 （companion_spectral_factor，:199-243）： AdaptiveRootSolver（同第 29 章链）求 R 全部根； 根成 (z, −z*) 对，LHP 选择 select_lhp_roots （:251-338，见下）；s=0 增益校正 scale = √(R(0)/(D(0)D̃(0)))；
  3. 伴随结果必须过校验，否则 typed 报错 （NumericalFailure("spectral factorization: companion-matrix factor failed para-product verification (|D(jω)|² ≠ R(jω))")）——不静默出错因子；
  4. 两者输出过 monic()（:421-433，相位归一，|lead| 保留； |lead| < 1e-15 no-op）。

LHP 选择 select_lhp_roots（:251-338）三遍：

  • 按实部升序；
  • LHP 遍：取 re < −1e-12 且有限的根，标记其镜像 −conj(z) 已用 （镜像匹配 1e-6·(1+|·|)），到 target_count 停；
  • 虚轴遍：不足时取 |re| ≤ 1e-12 的纯虚根，微 nud 到 −1e-14 入 LHP；
  • 兜底：只补 re < −1e-9 的真 LHP 根（防静默拉进 RHP/纯虚根 → 非最小相位）； 不足则 D 降度、para-product 校验失败 → 报错。

校验 para_product_verified（:349-372）：虚轴 8 点 （ω = 0.375·k·√(deg+2)，k=1..8），相对误差 (|D|²−|R|)/|R|（|R| 小时用绝对）≤ 0.01。 局限（有测试钉死）：这是幅值校验——对实 R，最小相位与最大相位反因子 共享 |D(jω)|² 都能过；最小相位由 select_lhp_roots 的 LHP 偏置强制， 不由该校验。

27  双频带 route-α 与自由度限制

27.1 本章解决什么问题

双频带（dual-band）滤波器在两个不相交带内同时等纹波。 MFS 用 route-α：在单一正轴区间上对实根特征函数强制等纹波， 用 LM 解出反射零点，再复用单带 Feldtkeller 装配。 本章给算法、K≥3 自由度墙（为什么只支持 K=2）与文献锚点。

27.2 route-α 等纹波问题

入口 multi_band_chebyshev_polynomials（src/approx/multi_band.rs:351）。 特征函数 K(w) = F(w)/P(w)（实根、对称）在单一正轴区间上强制等纹波。 反射零点 F(w) = ∏(w²−r_k²)，n = order/2 个正零点（阶数必须偶）。 一个正区间 (a,b) 上 |K| 在 n+1 处取峰（n 零点之间 + 两端）， 等纹波 = n+1 方程 / n+1 未知（含共享电平）⇒ 只对 M=1 个正轴区间是平方（可解）。

27.3 LM 求零点 solve_rz

solve_rz（multi_band.rs:115-204）：

  • 20000 点网格找 n+1 峰（:117-120），残差 = 各峰偏离均值；
  • 前向 FD Jacobian：δ_j = 1e-7·max(1, |rz_j|)（:137）；
  • 正规方程 (JᵀJ + λ·diag(JᵀJ))·dp = −Jᵀr（高斯消元部分主元， 奇异枢轴 < 1e-30 → NumericalFailure，:224）；
  • 可行域约束：零点须严格在 (lo, hi) 内（v ≤ lo+1e-9 || v ≥ hi−1e-9 拒绝步，:167）；
  • λ 适应：接受（cost 下降）→ λ×0.5（min 1e-10）；拒绝 → λ×2； λ > 1e12 中断（:175,187,190）；
  • 收敛 √base_cost < 1e-12（:129）； 失败门 √base_cost > 1e-6 → NumericalFailure（:196）。

27.4 Feldtkeller 装配（复用单带）

解出正零点后 F_s = ∏(s² + r_k²)，P_s 由传输零点 （±jz 对，原点零点单根；去重避免对称列表 {0,±z} 双计）， find_eps + build_e_polynomial_stage 复用第 8–9 章 （route-α 不走 A 阶段，A=None），输出 GeneralizedChebyshevData → PolynomialSet 直接喂 MatrixSynthesisEngine 不变。 这是"高级功能复用基础算法"的范例：双频带只换了"求反射零点"那一步（LM 等纹波）， E/P/综合/矩阵全复用单带路径。

27.5 K≥3 自由度墙（DOF Wall）

约束计数：等纹波对 M 个正轴区间施加 N/2 + M − 1 个独立约束于 N/2 个零点。仅 M=1 是平方；M≥2 过定 M−1 个。

实现事实（multi_band.rs:383-392）：若正轴通带区间数 pos.len() ≠ 1 ⇒ MfsError::NotImplemented， 明说"实根特征只能在单一正轴区间等纹波；K≥3（跨原点中频带或 2+ 正轴带） 过定 M−1 个，需复根（Zolotarev）或多函数特征"。 实测（2026-10-05，architecture.md #5）：M=2/3 残差 5.7e+2 / 4.2e-2 vs M=1 对照 1.7e-9——确证 DOF 墙，非实现缺陷。 输入验证（:357-375）：bands.len() < 2 → InvalidFrequency； finite_count > order → DimensionMismatch； 阶数 0 或奇 → InvalidOrder（positive_rz_count）。

27.6 文献锚点（Cameron 2011 Fig. 25）

双通带锚定（tests/multi_band.rs）：阶 10、RL 22 dB、 带 [−1,−0.35] ∪ [0.35,1]、5 个传输零点 {0, ±0.25420871, ±1.15728568}。 4001 点网格 [−2,2] 上五道门：

  1. 响应不变：max|ΔS11|、max|ΔS21| < 1e-3 vs fixture 矩阵；
  2. 逐带等纹波：最差带内 |S11| = −22 dB ±1；
  3. 无耗性：max‖|S11|²+|S21|²−1‖ < 1e-10；
  4. 传输零点：每个 TZ 处 ±0.005 窗内 |S21| < −40 dB；
  5. 外阻带：|w|∈[1.10,2.0] 最差 |S21| < −15 dB。

解出零点与 oracle 差 ≤5e-4（multi_band.rs:455-475 注释）。

27.7 本章小结

双频带 route-α = 单正轴区间等纹波（LM 解 n 个正反射零点，20000 点峰定位、 FD Jacobian、λ 适应、√cost>1e-6 失败门）+ 复用单带 Feldtkeller 装配。 K≥3 是自由度墙（N/2+M−1 约束 vs N/2 零点，仅 M=1 平方），typed NotImplemented， 实测残差确认。Cameron 2011 Fig.25 锚定（5 门）。第五篇最后一章 LM 优化。

28  LM 优化、参数提取与数值 Jacobian

28.1 本章解决什么问题

Levenberg–Marquardt（LM）非线性最小二乘，用于两个工作流： 调谐（tune：让矩阵匹配目标 S 参数响应）与提取（extract： 从测量 S2P 数据恢复耦合矩阵）。 本章给参数化、残差、数值 Jacobian、LM 步与收敛判据—— src/optimize.rs 的 optimize_matrix（:337）。

28.2 参数化（冻结非零模式）

extract_parameters（optimize.rs:61-108）按固定序取 |val| > 1e-15 的源/负载/交叉/对角/直接耦合作为自由参数； rebuild_matrix 把参数对称写回模板的 clone，≤ 1e-15 的冻结为模板值。 ⇒ 恢复矩阵共享模板的稀疏模式，extract_matrix 只能拟合横向族 （模板 = 粗 inline 链）。

28.3 残差

compute_residuals：每个网格点 4 个残差分量 （S11 re/im、S21 re/im——全复数，非幅度），共 4·|grid| 个。 当前响应经 evaluate_normalized_with_settings（[§19.6](#sec196)）。 目标 Σr² 对单分量符号翻转不敏感（相位符号歧义不可钉—— S₂₁ 与 −S₂₁ 物理等价）。

28.4 数值 Jacobian

compute_jacobian：前向 FD，δ_j = 1e-7·max(1, |param_j|) （尺度感知步长）。扰动求值失败（远离解盆奇异）时 步长减半重试 ≤4 次。这是"病态输入不崩、而是退步"的工程处理。

28.5 LM 步（Marquardt 对角阻尼）

lm_step：解

(JᵀJ + λ·diag(JᵀJ))·Δp = −Jᵀr (28.1)

高斯消元部分主元（枢轴 < 1e-20 跳过）。 OptimizeConfig（optimize.rs:17-32）：max_iterations（默认 200）、 tolerance（1e-8）、lambda（1e-3）、optimize_diagonals/ optimize_ports（默认 true）、unloaded_q（∞）。

28.6 接受 / 收敛判据

optimize_matrix 主循环（:373-427）：

  • 接受：当 trial_cost < cost（λ×0.5）否则 λ×2， λ > 1e12 中断；
  • 收敛判据（关键实现细节）：只在"上一步被接受"且 |prev_cost − cost| < tol 时成立。 不要对"运行最优比"判（接受后次步 cost==best 会误判收敛）； 不要对"拒绝步"判（那是停滞不是收敛）——这是 review 修正过的判据。

产物 OptimizeResult{matrix, cost, …}（:39-46）。

28.7 可复现锚点

实测（tests/optimizer_integration.rs）：order-6 恢复（从扰动矩阵 恢复原矩阵）+ 提取（从 S2P 样本恢复）。 benches/optimizer.rs 基准 orders 4/6/8 的 tune + extract 收敛。 benches/synthesis.rs 含优化器门（5 gates 之一）。

28.8 数值细节与边界

注意 / 拒绝 LM 是局部方法：收敛到最近极小，不保证全局。 extract_matrix 受模板稀疏模式限制（只能拟合横向族）—— 若要恢复折叠/箭头结构，模板需相应设置。 λ 发散（>1e12）→ 中断（返回当前最优，不报错但 cost 不收敛）； Jacobian 奇异（枢轴 <1e-20）→ 跳步。 残差用全复数 S 参数（非幅度）——对相位翻转不敏感是有意的（物理等价）。

28.9 本章小结

LM = 参数化(冻结非零模式) + 4·|grid| 复数残差 + FD Jacobian(δ=1e-7·max(1,|p|), 奇异步减半≤4) + Marquardt 对角阻尼 (JᵀJ+λdiag)Δp=−Jᵀr + 接受(λ×0.5/×2, λ>1e12 停) + 收敛(仅在接受步且 |Δcost|<tol)。调谐/提取两工作流，order-6 实测锚定。 第五篇结束；第六篇数值可靠性与工程使用。

29  求根器链与数值稳定性

29.1 本章解决什么问题

综合链里所有求根（E 多项式、分母、谱密度 R）都走同一条 AdaptiveRootSolver 链。本章给三级求根器的算法、门限、 为何不用 nalgebra 伴随矩阵、以及高阶稳定性边界。

29.2 AdaptiveRootSolver 链

AdaptiveRootSolver（approx/complex_poly.rs:805-823， impl :816-842）按顺序尝试，成功即返回，失败 fall-through：

  1. FaerRootSolver（faer 复伴随矩阵特征值，首选）；
  2. DurandKernerRootSolver（迭代法，fallback）；
  3. AberthRootSolver（last resort）。

关键实现事实（:56-72 文档）：CompanionMatrixRootSolver （nalgebra Schur）故意不在链中——其复系数 2n×2n 实嵌入分支会返回 共轭翻转的伪根（有专门回归测试钉死）。它只保留为实系数测试 oracle。 不是"DK 优先"——是 faer 优先（旧文档曾误述）。

29.3 FaerRootSolver（伴随矩阵 + 平衡 + 后向残差门）

FaerRootSolver（complex_poly.rs:660-810）：

  1. monic 归一（:679-684）；
  2. 建复伴随矩阵：次对角 1、末列 −c_k（:686-695）；
  3. Parlett–Reinsch 对角相似平衡（:704-742）：至多 degree 次 sweep； 每步 W ← D·W·D⁻¹，d_i = sqrt(col_norm/row_norm) 钳到 [1e-100, 1e100]，当 row_norm < 0.5·col_norm || col_norm < 0.5·row_norm 时应用； row_norm ≤ 1e-300 || col_norm ≤ 1e-300 跳过。 平衡改善特征值条件数（高阶关键）；
  4. balanced.eigenvalues::<c64>()（:744）；
  5. 后向残差门（:778-786）：max_backward_residual(&normalized, &roots)， 接受当 !roots_contain_non_finite(roots) && max_backward ≤ FAER_BACKWARD_RESIDUAL_TOL (= 1e-3) （:867）。拒绝 → NumericalFailure，让链 fall-through。 后向残差 = |p(r)| / Σ_k |c_k|·|r|^k（尺度无关，scale.max(1e-300)， max_backward_residual :880-901）。

为什么有后向残差门：病态伴随矩阵的特征值可能是"伪根"（后向残差大）。 门把它变成 typed 失败 + fall-through，而非静默出货垃圾特征值。

29.4 DurandKerner 与 Aberth

DurandKerner（:266-360）：monic 归一（拒 leading.norm_sqr() ≤ 1e-24）； Cauchy 半径 1 + max_k |c_k|；黄金角初始化 （golden_angle = 2.399_963_229_728_653 = 2π/φ²，:304）； max_iterations = (128 + (degree−10)·4).min(512)；convergence_tol = 1e-13； DK 更新 delta = p(root)/Π(root−root_j)（denom.norm_sqr() ≤ 1e-30 跳过）； 收敛 max_delta ≤ 1e-13 && 无非有限；残差 fallback max_residual < 1e-8（:353）；否则 NumericalFailure。

Aberth-Ehrlich（:374-490）：同初始化；max_iterations = (200+(degree−10)·6).min(800) （比 DK 多）；Newton 修正 w = p(z)/p′(z) + Aberth 和 Σ 1/(z_k−z_j)， delta = w/(1 − w·aberth_sum)（分母近零退回纯 Newton）；同 1e-8 残差 fallback。

29.5 数值稳定性：为什么 faer 优先

复多项式求根本质病态（根对系数扰动敏感）。三级链的稳定性排序：

  • faer 伴随 + 平衡：特征值方法，Parlett–Reinsch 平衡直接改善条件数， 对高阶（N≥20）最稳；后向残差门兜住病态情况；
  • Durand-Kerner：O(N²) 迭代，精度退化 O(N²εmach)（这就是第 12 章 自适应极点容差 1e-6·(N/5)² 的由来）；
  • Aberth：带 Newton 修正，局部收敛快，作 last resort。

实现事实：benches/root_solvers.rs 对 4 个求根器 （DurandKerner、Aberth、CompanionMatrix、Faer）在 degree 10/20/30 测残差， examples/solver_accuracy_comparison.rs 做 orders 4–40 的残差对照—— 实测 faer 在高阶残差最小（这是 faer 优先的实测依据）。

29.6 高阶稳定性边界

实现事实（README + examples/high_order_stability.rs）： 无耗全极点验证稳定到阶 28、有限传输零点稳定到阶 24（RL 20–22 dB）， 经自适应极点轴容差。阶 30+ 可能被 typed NumericalFailure 拒绝 （极点实部超 1e-6·(N/5)² 容差）——边界是设计相关的（零点布局影响）。 high_order_stability 示例（orders 10–40）给出验证边界 + 可复现的拒绝。

不要扩大声明 "高阶稳定到 28/24"是已验证参数范围（全极点/有限零点、RL 20–22）， 不是对所有输入的保证。阶 30+ 拒绝是 typed 行为（有边界文档），不是静默错。

29.7 本章小结

求根 = faer 伴随+Parlett–Reinsch 平衡+后向残差门(1e-3) → Durand-Kerner(1e-13, 残差 1e-8) → Aberth(更多迭代) 三级 fall-through 链。nalgebra 伴随意外的伪根被排除在链外。 高阶稳定到 28(全极点)/24(有限零点)，30+ 可能 typed 拒绝（设计相关）。 下一章容差、尺度、聚类与病态。

30.3 尺度原则

阈值设计遵循三条尺度原则：

  1. 相对优先：凡涉及"大小比较"的阈值尽量相对（1e-10·‖·‖、 1e-12·max(1,|a|,|b|)），只对绝对量（如极点实轴噪声、dB 地板）用绝对值；
  2. 分离噪声与信号：阈值设在"求根/旋转噪声量级"（~1e-10..1e-13）与 "物理量量级"（~1e-3..O(1)）之间的空隙；空隙不够时（如重根 1e-5 vs 极点间距 1.6e-3） 用单链聚类 + 均值/簇大小而非重推系数（病态）；
  3. 随阶数自适应：精度退化 O(N²ε) 的地方（极点轴容差）显式乘 (N/5)²， 不固定 1e-6（否则高阶误拒）。

30.4 病态输入的处理策略

  • 病态伴随矩阵（求根）→ faer 后向残差门 fall-through 到迭代法；
  • 重根 → 单链聚类 + Laurent 主部（横向链拒绝 m≥2，[§12.2](#sec122)）；
  • 近奇异 Schur（快路径）→ 该点 typed 失败 → 落回 LU（[§20.3](#sec203)）；
  • 病态 LM 步（优化）→ 扰动失败步长减半≤4（[§28.4](#sec284)）；
  • 全有限 ε≤1 → typed PreconditionViolation（[§8.4](#sec84)）；
  • 非有限值 → 门自动失败（[§21.3](#sec213)）/ 求根门拒绝。

共同点：病态不是静默产出近似答案，而是 typed 失败 / 回退 / 显式拒绝。 这是库的核心错误策略（[§31](#ch31)）。

30.5 本章小结

阈值分六类（求根门、聚类、极点/残差分类、矩阵小值、对称、退化地板）， 遵循"相对优先、分离噪声与信号、随阶数自适应"三原则。病态一律走 typed 失败/回退/拒绝， 不静默近似。下一章支持边界与 typed error 体系。

31.4 诊断信息与处理方向

每个 typed error 的 Display 消息带具体值与替代建议：

  • 全有限 ε≤1 → 消息含实际 ε 值 + "改用混合零点（至少保留一个 ∞）"；
  • 通带零点 → 消息指明 |z| 值与 Feldtkeller 原因；
  • 阶 30+ 拒绝 → 消息含极点实部与容差（指向设计相关边界）；
  • 多频带 K≥3 → 消息明说"需复根(Zolotarev)/多函数特征"。
处理原则 库不自动建议改设计目标来掩盖失败。拒绝消息给"为什么不行 + 什么配置可行"， 但不擅自放宽规格。用户据此调整（如改混合零点、降阶、放宽 RL），而非库静默妥协。

31.5 与验证的关系

typed error 是构造/算法期的拒绝；verify_against_spec （[§32](#ch32)）是响应期的规格检查（返回 pass/fail/skipped，不抛错）。 两者互补：前者保证"能综合"，后者保证"综合出的响应满足规格"。 synthesize() 成功不等于规格满足（[§1.6](#sec16)）。

32.1 本章解决什么问题

32.2 verify_against_spec（绝对规格门）

  4. ResponseEvaluationStage：CouplingMatrix + Grid(+Mapping) → SParameterResponse。

run_full_pipeline(request)（一次全跑）、run_stage（增量单 stage）、 save_context/load_context（JSON 持久化恢复）、 describe_schema()（JSON Schema）。 频率映射：request 带 mapping（bandpass/lowpass）则经 MappingConfig::build_mapping 评估物理 Hz 网格；否则网格视为已归一化。 未知/不完整 mapping → InvalidFrequency（不再静默忽略，历史修正）。

CLI 子命令：design、io、multiplexer、target、 optimize（调谐/提取，[§28](#ch28)）。 tests/cli_integration.rs（551 行）验证 JSON/stdin I/O、--stage flag、 optimize/extract 子命令、save/resume 端到端。

33.5 接口 vs 算法的分离

为什么 CLI/Python/JSON 在本篇 它们是接口包装（同一 FilterDesign 的三种暴露面），不含独立数学。 核心数学在第二～五篇。把接口混入数学章节会让"算法在哪实现"的追踪变模糊—— 故按任务要求分离。追踪"某算法在哪"：见附录 C 映射表。

F  已知限制和未验证范围

明确保留，不扩大声明。每项标注"为什么"与"什么情况下适用"。

  1. 通带传输零点（|z|<1）不支持——单函数实根广义 Chebyshev 原型无法实现带内零点 （Feldtkeller 破坏，E1 2026-10-05 调查）。需多函数特征（未实现，研究方向）。 入口 typed InvalidTransmissionZero 拒绝（[§6.4](#sec64)）。
  2. 横向综合的重复极点——残差展开（Laurent）与快路径能处理，但横向链每谐振器只表 一个简单极点 ⇒ typed NotImplemented（[§12.2](#sec122)）。 未验证范围：非横向拓扑（折叠/箭头）下重根的综合未覆盖。
  3. Wheel 拓扑弃用——当前是 Arrow 别名（[§16.3](#sec163)）。
  4. LU 群延迟依赖对称——非对称输入（opt-out 构造）静默算错群延迟、幅度不受影响 （review 0.6.1 P1-3，[§19.5](#sec195)）。构造端对称守卫兜底，但这是已知不变量。
  5. 多工器简化路径保真度有限（相邻信道）——默认频移微扰不收敛到机器容差。 全谱路径 full_iteration(true) 已收敛并门锚定 （Type-I 阶 2–8 + Type-II + N=3/4，[§26.7](#sec267)）。 未验证范围：N>2 非理想 Type-I 无论文依据，typed 拒绝（不臆造数学）。
  6. 多频带仅双通带（K=2）——K≥3 是 DOF 墙（typed 拒绝，实测残差确认， [§27.5](#sec275)）。真 K≥3 等纹波需复根（Zolotarev）或多函数特征（未实现）。
  7. 全有限 ε≤1 不可行域——近带边零点/高 RL 使 ε≤1，全有限公式不可行， typed PreconditionViolation（[§8.4](#sec84)）。此域 2026-10-12 才文档化 （review P1-1），此前表现为误导性通用"系数须有限"错误。
  8. 高阶能力仅描述已验证参数范围——稳定到 28（全极点）/24（有限零点）， RL 20–22 dB（[§29.6](#sec296)）。不扩大成所有输入的保证；阶 30+ 设计相关 可能 typed 拒绝。无 >8 阶的文献 fixture（高阶靠自验证，非文献锚定）。
  9. 响应曲线未提供——本书不含实测响应图（避免示意数据冒充实测）。 复现需运行 design.response() 保留输入与生成脚本（[§34.3](#sec343)）。
  10. fixture 的 source-to-output 可追溯——当前 fixture 是"文献支撑的工作流锚 + 两个精确低阶数值锚"，不是"精确复现公开耦合表"的强声明（[§32.6](#sec326)）。
  11. M–T 一次性捕获滞后——返回的 common 描述第 k 迭代、s_roots 是 k+1， 滞后由 convergence_error 界定，有意不重算（[§26.4](#sec264) 注）。
  12. Python 绑定 ABI 敏感——需 Rust ≥ 1.86 + 匹配 ABI 的 Python； 跨 ABI 行为未逐一验证（接口包装，数学与 Rust 一致）。
