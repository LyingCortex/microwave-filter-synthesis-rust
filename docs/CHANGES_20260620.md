## 1. Bug修复：共轭极对综合中的×2因子

**文件**: `src/synthesis/residues.rs`  
**行号**: ~368 (ComplexPair分支)

**问题**: 
`combine_conjugate_pair()`对共轭极对的residue做了`2*Re(r)`后再开根号，
导致源/负载耦合值偏大√2倍。

**原因**: 
每个极点（包括共轭对的两个成员）在transversal矩阵中占据独立的行/列，
不应做共轭合并。Cameron 2003标准定义为 `M_Sk = √(Re(r11_k))`，无2倍因子。

**修复**: 
将ComplexPair路径改为与Real路径相同的逻辑——每个极独立提取`Re(residue)`再开根号。

**验证**: 4阶all-pole滤波器的M_S1从错误的1.5635修正为正确的1.1055，
与Python引擎和Cameron文献数值完全一致（误差<1e-14）。

## 8. Bug修复：Folded变换循环上界错误

**文件**: `src/matrix/core.rs`  
**行号**: ~333 (`to_folded`方法)

**问题**: 
第一个旋转循环（列操作消零）的上界使用了固定的`filter_order`：
```rust
// 修复前（错误）
for col_in_row_oper in ((row_oper_num + 2)..=filter_order).rev()
```

当`row_oper_num > 0`时，会多旋转不需要的位置，导致folded矩阵不是标准Cameron形式。

**正确形式**（与Python/Cameron一致）：
```rust
// 修复后
for col_in_row_oper in ((row_oper_num + 2)..=(filter_order - row_oper_num)).rev()
```

**影响**:  
- N=4, 2零点时：第二轮(row_oper_num=1)错误地旋转了位置[4,3]而非只旋转[3]
- 产出的folded矩阵有非零对角线和多余的非零耦合项
- S参数不受影响（旋转是similarity变换，保持特征值）

**标准Folded形式特征**（Cameron 2003）:
- 对角线全零（同步调谐）
- 仅次对角线(Mk,k+1)和特定交叉耦合非零
- 对于N=4, 2零点: 仅M14(或M25)为非零交叉耦合

**验证**: 修复后两个引擎的folded CM完全一致（误差2.8e-15）。

## 9. Bug修复：CQ placement z_loc解读方式 (Python端)

**文件**: `src/domain/coupling_matrix.py` (行1670, 1686)

**问题**:
`CascadeQuartets`用`min(pos[0], pos[1])`作为triplet center。
当z_loc=[[1,3]]时，`min(1,3)=1`导致triplet pull到center=1，
旋转了与Source直连的resonator 1，污染了M_S1耦合。

**修复**:
```python
# 修复前
target_position = min(pos1[0], pos1[1])

# 修复后
target_position = (pos1[0] + pos1[1]) // 2
```

使用中点作为triplet center。z_loc现在保持物理含义：
`[from, to]` = 交叉耦合连接的两个谐振器编号。

**新增文件**: `src/domain/cq_placement.py`
- `compute_cq_positions(order, num_zero_pairs)` — 自动计算合法CQ位置
- `validate_cq_positions(order, positions)` — 验证约束
- `cq_positions_to_z_loc(positions)` — Position→z_loc转换

**CQ placement约束**:
1. triplet center ≥ 2（不旋转Source连接的resonator 1）
2. triplet center ≤ order-1（不旋转Load连接的resonator N）
3. quadruplet不重叠
4. 每个quadruplet占4个连续谐振器

**z_loc语义（修复后）**:
```
Position (k, k+3) → z_loc = [[k, k+2], [k+1, k+3]]
  triplet centers = (k+k+2)//2=k+1, (k+1+k+3)//2=k+2

示例 8阶2对零点:
  Positions: [(1,4), (5,8)]
  z_locs: [[1,3], [2,4], [5,7], [6,8]]
  centers: 2, 3, 6, 7 (全部 ≥2 且 ≤7)
```

**验证结果**:
- 8阶对称4零点：Source/Load干净，M[1,4]=-0.1975, M[5,8]=-0.0556 ✅
- 6阶对称2零点：Source干净，M[1,4]=-0.1429 ✅

## 10. Bug修复：extract_box_section cross-pivot旋转 (Python端)

**文件**: `src/domain/coupling_matrix.py` (行~1760)

**问题**:
Cross-pivot旋转的pivot索引和角度公式都错误：
- 错误pivot: (p+1, p+2) — 旋转了错误的行列
- 错误公式: `0.5*arctan2(2*Mij, Mjj-Mii)` — Jacobi对角化公式符号不匹配

**修复**:
```python
# 正确pivot: (p, p+1) — 旋转trisection的中心和邻接谐振器
i_idx = p      # trisection center
j_idx = p + 1  # next resonator

# 正确公式: Jacobi消零，取负号匹配旋转矩阵R=[[c,-s],[s,c]]约定
theta_box = -0.5 * arctan(2*M[i,j] / (M[i,i] - M[j,j]))
```

**BOX标准形式** (4谐振器，1个传输零点):
```
     1    2    3    4
1 [  0  M12  M13   0  ]
2 [ M12  0    0   M24 ]    ← M23=0 (被cross-pivot消除)
3 [ M13  0    0   M34 ]
4 [  0  M24  M34   0  ]
```

特征: M13≠0, M24≠0, M14=0, M23=0

**零点产生机制**:
```
路径A: S→1→2→4→L  (通过M12, M24)
路径B: S→1→3→4→L  (通过M13, M34)
两条路径在某频率相消 → 1个传输零点
```

**算法**: CT(trisection) → Jacobi旋转消除M23 → BOX

**验证**: 4阶1零点(Ω=1.8), M[2,3]=0(精确), S参数保持不变 ✅

## 11. 新增：BOX拓扑提取 (Rust + Python绑定)

**文件**: `src/matrix/sections.rs`, `src/python.rs`

### 实现

```rust
// src/matrix/sections.rs
pub(crate) fn extract_box_section(&self, transmission_zero: f64, span_start: usize) -> Result<Self>
pub(crate) fn extract_box_sections(&self, zeros: &[f64], spans: &[[usize; 2]]) -> Result<Self>
```

### 算法

```
输入: Arrow矩阵, 传输零点Ω, BOX范围[k, k+3]

Step 1: extract_triplet(Ω, center=k+1)
  → 产生trisection: M[k,k+2]≠0 (cross), M[k+1,k+2]≠0 (inline)

Step 2: Jacobi旋转消除 M[center, center+1]
  pivot = (center, center+1) = (k+1, k+2)
  theta = -0.5 * arctan(2*M[i,j] / (M[i,i] - M[j,j]))
  → M[k+1,k+2]=0, 产生M[k+1,k+3]≠0

输出: BOX矩阵
  M[k, k+2] ≠ 0    (cross coupling 1)
  M[k+1, k+3] ≠ 0  (cross coupling 2)
  M[k+1, k+2] = 0  (eliminated)
```

### BOX标准矩阵模式 (4谐振器块)

```
        k    k+1   k+2   k+3
k   [   0   Mk,k+1  Mk,k+2   0    ]
k+1 [ Mk,k+1  0      0    Mk+1,k+3]
k+2 [ Mk,k+2  0      0    Mk+2,k+3]
k+3 [   0   Mk+1,k+3 Mk+2,k+3  0  ]

特征: M(k+1,k+2)=0, 两条交叉耦合产生1个传输零点
```

### 零点产生机制

```
路径A: →k → k+1 → k+3→   (通过Mk,k+1和Mk+1,k+3)
路径B: →k → k+2 → k+3→   (通过Mk,k+2和Mk+2,k+3)
两路径在某频率相消 → 1个传输零点
```

### Python绑定

```python
d = mfs.bandpass(4, 25.0, 2e9, 100e6, zeros=[2090e6])

# 多个BOX (8阶2零点)

```

### 与CT/CQ的API对比

```python

d.cq([[1, 3], [1, 4]])           # CQ: span=2+span=3混合
```
